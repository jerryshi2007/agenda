## Story 拆解

### EVT-ST-01：日程创建流程

| 字段 | 值 |
|------|-----|
| 本地 ID | EVT-ST-01 |
| 标题 | 日程创建流程（三种类型 + 时间槽 + 冲突检测） |
| 描述 | 实现完整的日程创建流程：选孩子 → 选类型 → 填字段 → 确认。支持课后活动、日常作息、作业任务三种类型，每种类型的字段差异正确处理。时间槽模型采用"快速填充 + 逐天微调"方案（方案 B）。支持从模板快速创建日程（Should，见下方优先级说明）。实现日程冲突检测（针对同一孩子的软提示，不阻止创建）。覆盖全部输入校验（名称必填/长度限制、时间合法性、至少一天等）和相关空状态。 |
| 覆盖用户故事 | US-EVT-01 [Must], US-EVT-02 [Must], US-EVT-03 [Must], US-EVT-04 [Should], US-EVT-05 [Must] |
| 覆盖边界异常 | BE-01 ~ BE-08, BE-11, BE-12 |
| 优先级 | Must（含 1 个 Should 子故事 US-EVT-04；整体 Story 优先级按其最高优先级的子故事判定） |
| 预估工时 | 3 个工作日 |
| 依赖 | 认证模块（需登录态）、家庭管理模块（需家庭和孩子数据） |
| 飞书链接 | 待回填 |
| 状态 | 待开发 |

**关键交互：**
- 选孩子步骤：展示家庭中所有孩子，支持多选；仅一个孩子时预选但可取消；无孩子时显示空状态 + 跳转家庭管理入口
- 选类型步骤：三个类型卡片（课后活动/日常作息/作业任务）+ 底部"从模板创建"入口
- 填字段步骤：根据类型展示不同字段集合；时间槽采用"选星期几 → 设默认时间 → 可选逐天微调"流程
- 确认创建：预览摘要 → 提交 → 冲突检测（如有重叠则弹提示，用户可选择继续或返回）→ 返回日历视图
- 模板创建：选择模板 → 自动填充字段 → 按需微调 → 关联孩子 → 确认

**关键数据结构：**
- 三种类型共享 Event 核心结构，类型差异通过字段存在性表达（如"地点"仅课后活动有）
- 时间槽：7 元素数组，每个元素 = { dayOfWeek, startTime, endTime }，未安排的天不出现在数组中
- 作业任务：截止日期 + 可选建议时间段，不使用时间槽

### EVT-ST-02：日历三视图与筛选

| 字段 | 值 |
|------|-----|
| 本地 ID | EVT-ST-02 |
| 标题 | 日历三视图（月/周/日）+ 筛选 |
| 描述 | 实现日历月视图、周视图、日视图三种展示模式及其切换交互。按日程类型着色（课后活动=蓝、日常作息=绿、作业任务=橙），孩子归属通过头像/名字区分。顶部筛选栏支持按孩子、按类型筛选，筛选条件跨视图保持。月视图仅色点 + 点击跳日视图；周视图卡片含时间+名称+头像+状态图标；日视图时间线含完整信息。涵盖所有空状态、滑动防抖、跨月点击等边界场景。家长端默认周视图，孩子端默认日视图。 |
| 覆盖用户故事 | US-EVT-16 [Must], US-EVT-17 [Must], US-EVT-18 [Must], US-EVT-19 [Must] |
| 覆盖边界异常 | BE-09, BE-10, BE-15, BE-19 ~ BE-22 |
| 优先级 | Must |
| 预估工时 | 3 个工作日 |
| 依赖 | EVT-ST-01（需有日程数据才能非空展示；可先以空状态开发并预留数据接口） |
| 飞书链接 | 待回填 |
| 状态 | 待开发 |

**关键交互：**
- 视图切换：顶部分段控件 [月 | 周 | 日]，切换动画 ≤ 500ms
- 月视图：传统日历网格，每格日期数字 + 最多 3 色点（超出显示"+N"），今天高亮，非当月灰色，点击跳日视图
- 周视图：7 列按时间纵向排列，卡片颜色条 + 时间 + 名称 + 孩子头像 + 状态图标，点击进详情
- 日视图：时间线布局，卡片含完整信息（颜色条+时间+名称+孩子头像名+状态+类型+地点+备注），点击进详情
- 筛选栏：按孩子（单选/全部）+ 按类型（多选/全部），条件在所有视图保持一致
- 顶部导航：当前日期范围显示，点击弹出日期选择器；"今天"按钮快速回今天
- 左右滑动手势切换上一/下一周期（需防抖 300ms）

**关键数据流：**
- 视图切换时按需拉取对应日期范围的日程数据（非一次性拉全量）
- 筛选条件变更时重新请求数据（前端不自行过滤已加载数据，保证数据一致性）

### EVT-ST-03：日程详情页与全操作

| 字段 | 值 |
|------|-----|
| 本地 ID | EVT-ST-03 |
| 标题 | 日程详情页 + 编辑/删除/取消/打卡 |
| 描述 | 实现日程详情页的完整展示和所有操作入口。详情页展示基本信息（日期/时间/地点/孩子/备注）、重复信息（仅重复日程）、打卡记录。操作区含：打卡确认（含撤销）、编辑（分段开关：仅本次/全部日程，已打卡实例允许编辑且不重置打卡状态）、删除（确认弹窗：仅本次/本次及之后）、取消本次（独立按钮，支持恢复）。家长端和孩子端差异处理（编辑/删除/取消仅供家长端，打卡两端均可）。实现快捷打卡（日/周视图卡片上的快速打卡入口）、并发编辑冲突提示、网络异常重试。 |
| 覆盖用户故事 | US-EVT-06 [Must], US-EVT-07 [Must], US-EVT-08 [Must], US-EVT-09 [Must], US-EVT-10 [Must], US-EVT-11 [Must], US-EVT-12 [Must], US-EVT-13 [Must], US-EVT-14 [Must], US-EVT-15 [Should], US-EVT-20 [Must] |
| 覆盖边界异常 | BE-13, BE-14, BE-16, BE-17, BE-18, BE-23 |
| 优先级 | Must（含 1 个 Should 子故事 US-EVT-15；整体 Story 优先级按其最高优先级的子故事判定） |
| 预估工时 | 3.5 个工作日 |
| 依赖 | EVT-ST-01（需已有日程数据）、EVT-ST-02（快捷打卡需日历视图卡片） |
| 飞书链接 | 待回填 |
| 状态 | 待开发 |

**关键交互：**
- 详情页入口：日历视图点击日程卡片 → 进入详情页
- 布局结构：顶部导航（返回+标题+类型标签）→ 打卡状态区 → 基本信息区 → 重复信息区（仅重复日程）→ 打卡记录区 → 操作按钮区
- 编辑：点击"编辑"→ 进入编辑页（复用创建页，预填数据），顶部"仅本次/全部日程"分段开关，默认"仅本次"；切换时已填内容保留；作业任务不显示开关。已打卡实例允许编辑，打卡记录不重置。
- 删除：点击"删除"→ 确认弹窗，默认"仅删除本次"；作业任务直接确认删除
- 取消本次：独立按钮（不与编辑/删除混用），仅重复日程显示 → 确认弹窗 → 灰色+删除线显示；已取消的显示"恢复本次"按钮，点击立即恢复
- 打卡：未完成 → 点击"打卡确认" → 变已完成；已完成 → 点击"撤销打卡" → 变未完成；已取消/已逾期 → 不显示打卡按钮。后台记录打卡人 ID
- 快捷打卡：日/周视图卡片上的打卡图标 → 点击直接变更状态（不进详情页）；月视图不提供
- 家长端 vs 孩子端：编辑/删除/取消本次 → 仅家长端显示；打卡 → 两端均可；关联孩子 → 家长端显示全部，孩子端仅显示自己

**关键数据流：**
- 进入详情页时从服务端拉取最新数据（不依赖日历缓存），保证数据新鲜度
- 编辑/删除/取消/打卡操作使用乐观锁（版本号），冲突时提示用户刷新
