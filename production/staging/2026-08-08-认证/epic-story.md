## Story 清单

### Story A1: 隐私政策弹窗与静默登录

| 字段 | 值 |
|------|-----|
| **本地 ID** | AUTH-001 |
| **类型** | Story |
| **标题** | 隐私政策弹窗与微信静默登录 |
| **描述** | 实现首次打开时的隐私政策弹窗（勾选同意/拒绝流程），以及用户同意后的微信静默登录链路：wx.login → code 换 openid → 签发 JWT → 前端存储。覆盖正常流程和异常路径（wx.login 失败、后端超时、新用户自动创建账户、Storage 清除后重新登录、微信账号切换）。 |
| **关联 US** | US1: 隐私政策同意 / US2: 微信静默登录 |
| **优先级** | Must |
| **预计工时** | 2 天 |
| **飞书链接** | （待回填） |
| **状态** | 待开发 |

**验收要点**：
- 首次打开展示隐私政策弹窗，未勾选时同意按钮置灰
- 拒绝后展示静态提示页，不调用任何 API
- 同意后静默完成 wx.login + JWT 签发，用户无感知
- wx.login 失败时展示重试按钮
- 微信账号切换时正确匹配/创建账户
- 隐私政策版本号机制（版本更新后需重新同意）

### Story A2: JWT 登录态管理

| 字段 | 值 |
|------|-----|
| **本地 ID** | AUTH-002 |
| **类型** | Story |
| **标题** | JWT 登录态管理与静默续期 |
| **描述** | 实现 JWT 的签发、存储、请求携带、静默续期、过期处理全链路。包括：前端请求拦截器自动携带 Token、响应拦截器捕获 401 自动续期、并发 401 续期锁、续期失败降级处理、Token 篡改检测、Storage 满降级。后端实现 JWT 签发/验签、频率限制、时钟偏差容忍、密钥环境变量管理。 |
| **关联 US** | US4: 登录态管理 |
| **优先级** | Must |
| **预计工时** | 2 天 |
| **飞书链接** | （待回填） |
| **状态** | 待开发 |

**验收要点**：
- 所有 API 请求自动携带 `Authorization: Bearer <jwt>`
- 401 响应自动触发静默续期，用户无感知
- 多个 401 并发时仅执行一次 wx.login
- 续期失败时友好提示，Token 篡改/过期时走统一续期流程
- 登录/续期接口每用户每分钟 ≤ 10 次频率限制
- JWT 签名密钥通过环境变量注入，不进源码

### Story A5: 账户注销

| 字段 | 值 |
|------|-----|
| **本地 ID** | AUTH-005 |
| **类型** | Story |
| **标题** | 账户注销与 30 天缓冲恢复 |
| **描述** | 实现账户注销全流程：注销条件检查（须先退出所有家庭）、注销说明页、二次确认弹窗、后端标记注销+清除 Token。实现 30 天缓冲恢复机制：恢复页面展示倒计时、"恢复账户"和"知道了"两个操作。30 天到期后自动删除/匿名化数据，再次登录视为新用户。覆盖注销接口幂等性、网络异常保持原状态、并发注销/恢复处理。 |
| **关联 US** | US7: 账户注销 |
| **优先级** | Should |
| **预计工时** | 1.5 天 |
| **飞书链接** | （待回填） |
| **状态** | 待开发 |

**验收要点**：
- 注销前检查家庭关联，有家庭时拦截并提示先退出
- 注销流程：阅读说明 → 确认 → 二次确认 → 清除 Token → 关闭小程序
- 30 天内重新登录展示恢复页面，可一键恢复或保持注销
- 30 天后数据永久删除，再次登录创建全新账户
- 注销接口幂等，重复请求返回成功
- 打卡记录匿名化保留（移除 userId，替换为匿名标识符）
- 网络异常时不改变本地状态

## 依赖关系

```
AUTH-001 (隐私+登录) ──→ AUTH-002 (登录态) ──→ AUTH-003 (资料) ──→ AUTH-004 (我的页面)
                                              ↘ AUTH-005 (注销)
```

- AUTH-001 是前置依赖，所有后续 Story 依赖其完成的登录链路
- AUTH-002 与 AUTH-001 紧耦合，建议同一开发者连续实现
- AUTH-003 / AUTH-004 / AUTH-005 基于前两个 Story 可并行开发
