# 孩子展示模式模块 · 产品需求文档

> 版本：v1.0 | 日期：2026-08-06 | 状态：草案
>
> 所属产品：[家庭日程协作工具](index.md)
>
> 本文档为 `index.md` 的模块化拆分，聚焦孩子端三种展示模式（学龄前/小学/高年级）的详细设计。设置入口与配置界面已在 [家庭管理模块文档](module-family.md) 第 5 节定义，本文档**引用**不重复。其他模块设计见对应模块文档。

---

## 1. 模块概述

孩子端界面根据家长为孩子设置的展示模式，呈现不同的视觉和交互体验。展示模式是孩子端 UI 的"渲染开关"——同一份日程数据，根据模式以不同方式呈现给孩子。

**核心能力：**

- 三种展示模式：学龄前（3-6 岁）/ 小学（6-10 岁）/ 高年级（10-14 岁）
- 系统根据孩子年龄自动推荐默认模式，家长可随时更改
- 模式切换后孩子端下次进入页面自动生效
- 所有模式共享同一份日程数据，仅视图层差异

**与其他模块的关系：**

- 家庭管理：展示模式是孩子成员属性，设置入口在家庭管理 → 孩子设置（详见 [module-family.md §5](module-family.md#5-孩子展示模式设置)）
- 日程管理：孩子端日历视图（今日/周/月）的渲染受展示模式控制，日程数据本身不变
- 打卡与统计：打卡交互形式受展示模式影响（弹窗确认 vs 直接按钮），打卡记录和统计计算逻辑不受影响
- 认证与账户：JWT 携带用户角色和孩子模式标识，用于孩子端页面渲染

**分期：**

> 第一期统一使用小学模式，展示模式差异化 UI 在第二期实现。

## 2. 三种模式定义

### 2.1 模式对比总览

| 维度 | 学龄前（3-6 岁） | 小学（6-10 岁） | 高年级（10-14 岁） |
|------|:--:|:--:|:--:|
| 可用视图 | 仅今日视图 | 今日 + 周 + 月 | 今日 + 周 + 月 |
| 时间显示 | 时段标签（早上/上午/下午/晚上） | 具体时间（如 15:00-16:00） | 具体时间 |
| 卡片样式 | 大色块 + 卡通图标 + 极少文字 | 文字 + 图标列表 + 时间 | 接近成人视图 |
| 打卡方式 | 点击卡片 → 弹窗大确认按钮 → 轻量动画 | 点击打卡按钮，直接确认 | 点击打卡按钮，直接确认 |
| 状态颜色 | 红绿灯体系（绿/白/红） | 标准状态图标（✓/✗） | 标准状态图标（✓/✗） |
| 自主添加日程 | ✗ | ✗ | ✓（所有类型，无限制） |
| 查看统计 | ✗ | 本周完成率 | 简化版个人统计 |
| 我的页面 | ✗ | 本周完成率 | 完成率 + 连续天数 + 按类型统计 |

### 2.2 模式选择依据

| 模式 | 目标年龄 | 推荐逻辑 |
|------|---------|---------|
| 学龄前 | 3-6 岁 | 孩子年龄 ≤ 6 岁，系统默认推荐 |
| 小学 | 6-10 岁 | 孩子年龄 7-10 岁，系统默认推荐 |
| 高年级 | 10-14 岁 | 孩子年龄 ≥ 10 岁，系统默认推荐 |

**注意**：年龄是参考依据，系统只做初始推荐，最终由家长决定。家长可随时更改，不受年龄限制。

## 3. 学龄前模式（3-6 岁）

### 3.1 概述

面向 3-6 岁幼儿，核心目标是"让孩子知道今天该做什么，并完成打卡"。不提供周/月视图（幼儿无周/月时间概念），仅聚焦"今天"。

### 3.2 页面结构

学龄前模式仅有一个页面：**今日视图**。无周视图、月视图、我的页面。

### 3.3 今日视图设计

#### 3.3.1 时段分组

全天日程按四个自然时段分组，不显示具体时间：

| 时段 | 时间范围 | 典型日程 |
|------|---------|---------|
| ☀️ 早上 | 6:00-10:00 | 起床、早餐、上学准备 |
| 🌤 上午 | 10:00-12:00 | 上午活动 |
| 🌤 下午 | 12:00-18:00 | 课后活动、作业 |
| 🌙 晚上 | 18:00-21:00 | 练琴、阅读、睡觉 |

- 时段图标使用卡通风格设计（非 emoji），具体视觉在原型阶段确定
- 每个时段一组，组内卡片按时间顺序排列
- 当前时段高亮，已过时段默认收起（已完成日程可折叠隐藏）
- 没有日程的时段不显示，不占空间
- 日程跨时段时，按日程**开始时间**归属时段。如 11:30-12:30 归属"上午"

#### 3.3.2 卡片内容

每张日程卡片显示：

| 元素 | 说明 |
|------|------|
| 卡通图标 | 代表日程类型的卡通形象（如 🎹 钢琴课用钢琴图标），非 emoji，统一设计 |
| 日程名称 | 大字体文字，如"钢琴课""练琴"（家长命名，尽量简短） |
| 时段标签 | 所属时段（早上/上午/下午/晚上），小字标注 |
| 状态指示 | 红绿灯颜色边框/背景 |

**不显示**：具体时间、持续时间、重复规则、备注等。

#### 3.3.3 状态颜色（红绿灯体系）

| 状态 | 颜色 | 含义 |
|------|------|------|
| 当前进行中 | 🟢 绿色 | "现在该做这个"——当前时段内最近的待完成日程，仅一个为绿色 |
| 待完成（未到时间） | ⚪ 白色/浅灰 | "还没轮到"——时间未到的日程 |
| 逾期未完成 | 🔴 红色 | "这个没做！"——已过时间但未打卡 |
| 已完成 | ✅ 绿色 + 大对勾 | "做完了！"——已打卡确认 |

- 日程类型色（课后活动蓝 / 日常作息绿 / 作业任务橙）作为卡片**背景色**，状态色作为**边框/状态指示条**，两者叠加不冲突
- 当前进行中只有一个（绿色），给孩子清晰焦点："有且只有一个绿色的事，先做它"

#### 3.3.4 打卡交互

```
孩子看到卡片（如"钢琴课"）
  ↓ 点击卡片
弹出大确认按钮
  ┌──────────────────────────────────────┐
  │           🎹                         │
  │       钢琴课 完成了吗？               │
  │                                      │
  │         [  ✓ 完成！  ]              │
  │                                      │
  └──────────────────────────────────────┘
  ↓ 点击确认
卡片变绿色 + 大 ✓ + 轻微弹跳动画
  ↓
卡片下沉/收起，下一个待完成日程自动上移到顶部
```

**设计要点：**

| 要点 | 说明 |
|------|------|
| 确认按钮 | 大尺寸，易点击，配卡通图标，文字"完成！" |
| 动画反馈 | 轻量弹跳 + 变绿 + 对勾，非全屏动画（避免拖慢连续打卡） |
| 完成后行为 | 卡片下沉或收起，让"没做的"始终在顶部显眼位置 |
| 误触保护 | 弹窗确认防止幼儿无意识点击 |
| 撤销 | 第一期不做打卡撤销（幼儿不理解撤销概念） |

#### 3.3.5 空态

当日无日程时，显示友好的空态：

```
┌──────────────────────────────────────┐
│                                      │
│         🎉                           │
│     今天没有要做的事！                │
│     去玩吧～                          │
│                                      │
└──────────────────────────────────────┘
```

### 3.4 学龄前模式不提供的功能

- 周视图、月视图
- 我的页面
- 打卡撤销
- 自主添加日程
- 查看统计

## 4. 小学模式（6-10 岁）

### 4.1 概述

小学模式是孩子端的**基准视图**，第一期统一使用此模式。定位为"家长端的只读简化版"——孩子能看到所有日程和打卡，但无管理能力。

### 4.2 页面结构

| 页面 | 功能 | 与家长端差异 |
|------|------|-------------|
| 今日视图 | 时间线列表，显示具体时间 + 日程名称 + 类型图标 + 状态 | 不可编辑/删除/创建，无"取消本次"按钮 |
| 周视图 | 7 天日程概览，颜色区分类型 | 只读，不可编辑 |
| 月视图 | 月度概览，色点标识有日程的日期 | 只读，不可编辑 |
| 我的页面 | 简版——仅显示本周完成率 | 无成就/徽章，无切换家庭，无设置 |

### 4.3 今日视图

- 按时间线排列，显示具体时间（如"15:00-16:00"）
- 每项显示：类型图标 + 名称 + 时间 + 状态
- 顶部显示今日进度："已完成 3/5"
- 日程类型色与家长端一致（课后活动蓝 / 日常作息绿 / 作业任务橙）

### 4.4 打卡交互

- 点击打卡按钮，直接确认，无需二次弹窗（小学生已具备"有意操作"能力）
- 支持打卡撤销（与家长端一致，点击已打卡的日程可撤销）
- 打卡后状态图标更新为 ✓

### 4.5 周/月视图

- 与家长端日历视图逻辑一致，但卡片/色点不可点击进入编辑
- 点击日程跳转到日程详情页（只读模式）
- 颜色区分类型，与家长端色系一致

### 4.6 我的页面

仅显示本周完成率：

```
┌──────────────────────────────────────┐
│  我的                                │
├──────────────────────────────────────┤
│                                      │
│  👤 小明                             │
│                                      │
│  本周完成率                           │
│  ┌─────────────────────────────────┐ │
│  │                                 │ │
│  │        85%                      │ │
│  │    ████████████████░░░          │ │
│  │                                 │ │
│  │  已完成 17 / 20                 │ │
│  └─────────────────────────────────┘ │
│                                      │
└──────────────────────────────────────┘
```

### 4.7 小学模式不提供的功能

- 创建/编辑/删除日程
- 取消本次
- 切换家庭
- 邀请成员
- 设置孩子展示模式
- 成就/徽章
- 数据看板（家长端功能）

## 5. 高年级模式（10-14 岁）

### 5.1 概述

高年级模式接近成人视图，在小学模式基础上增加**自主添加日程**和**个人统计**能力。孩子可以自主管理部分日程，家长仍可创建和查看所有日程。

### 5.2 页面结构

| 页面 | 功能 | 与小学模式差异 |
|------|------|-------------|
| 今日视图 | 时间线列表 + 添加按钮 | 新增"+"按钮，可自主添加日程 |
| 周视图 | 7 天概览 | 与小学模式一致，只读 |
| 月视图 | 月度概览 | 与小学模式一致，只读 |
| 我的页面 | 完成率 + 连续天数 + 按类型统计 | 统计信息更丰富 |

### 5.3 自主添加日程

#### 5.3.1 权限范围

高年级模式不限制孩子录入日程的类型——所有三种类型（课后活动、日常作息、作业任务）孩子均可自主添加。

#### 5.3.2 添加流程

与家长端创建日程流程一致（详见 [module-event.md §4](module-event.md#4-创建流程)），但有关联差异：

| 差异点 | 孩子端 | 家长端（对比） |
|------|------|------|
| 关联孩子 | 默认自己，不可更改 | 可选择家庭中任意孩子 |
| 多选孩子 | 不支持 | 支持 |
| 创建后可见 | 孩子和家长均可见 | 同左 |

#### 5.3.3 自主添加的日程标记

- 卡片上区分来源：孩子自己添加的日程带"✏️"标记，家长添加的日程无标记
- 区分目的：家长在查看孩子日程时，能识别哪些是孩子自己安排的

### 5.4 打卡交互

- 与小学模式一致：点击打卡按钮，直接确认
- 支持打卡撤销

### 5.5 我的页面（统计）

显示简化版个人统计，不展示家庭其他孩子数据：

| 统计项 | 展示 |
|------|------|
| 本周完成率 | 百分比 + 进度条 + 完成数/总数 |
| 本月完成率 | 百分比 + 进度条 + 完成数/总数 |
| 连续完成天数 | 数字（如"连续 7 天"） |
| 按类型统计 | 课后活动/日常作息/作业任务各自的完成率 |

**不提供**：全家庭孩子对比、历史趋势图、导出/分享。

> 统计计算的逻辑规则（完成率公式、连续天数中断判定等）见 [打卡与统计模块文档](module-checkin.md)。

### 5.6 家长端联动

- 家长仍可为高年级孩子创建所有三种类型的日程
- 孩子自主添加的日程在家长端日历视图中正常显示，带"✏️"标记
- 家长可编辑/删除孩子自主添加的日程（家长权限高于孩子）

### 5.7 高年级模式不提供的功能

- 切换家庭
- 邀请成员
- 设置孩子展示模式
- 数据看板（家长端全家庭对比功能）
- 成就/徽章（第三期）

## 6. 模式切换

### 6.1 配置入口

家长在"家庭管理 → 成员列表 → 点击孩子 → 设置展示模式"中配置。详细设置界面已由 [module-family.md §5](module-family.md#5-孩子展示模式设置) 定义。设置页面提供"预览孩子端"按钮，可半屏预览当前模式下的孩子端效果。

### 6.2 生效机制

| 要点 | 说明 |
|------|------|
| 生效时机 | 家长保存后，孩子端**下次进入页面时**自动应用新模式 |
| 使用中切换 | 孩子正在使用时家长切换模式，不强制刷新，但下次切页面（如从今日视图切到周视图）或重新进入时自动应用 |
| 孩子端感知 | 无通知提示，仅界面展示方式变化 |
| 更改频率 | 无限制，家长可随时修改 |

### 6.3 对历史数据的影响

- 模式切换**不影响**任何历史打卡记录、日程数据、统计数据
- 切换只是改变"展示方式"，不改变数据本身
- 切换前后的打卡记录在同一孩子的记录上连续，不产生断层
- **孩子自主添加的日程**：从高年级切换到学龄前/小学模式后，孩子自主添加的日程数据保留，但学龄前/小学模式下孩子端不展示自主添加的日程（因该模式无此能力）。家长端仍可正常查看和管理。切回高年级模式后恢复可见

### 6.4 年龄增长提醒

- 系统不做年龄增长的自动切换提示
- 家长根据孩子的实际认知水平主动判断和调整

## 8. 边界与异常

| 场景 | 处理 |
|------|------|
| 孩子无日程（空态） | 学龄前模式显示"今天没有要做的事，去玩吧～"；小学/高年级模式显示空态引导"今天还没有日程" |
| 家长未设置展示模式 | 默认使用小学模式 |
| 孩子切换模式时正在打卡 | 不强制中断，当前操作完成，下次页面切换时生效 |
| 孩子年龄跨模式边界（如 6→7 岁） | 系统不自动切换，家长手动调整 |
| 家长切换模式后立即查看孩子端 | 孩子端切换页面后生效，家长端预览（如有）同步更新 |
| 网络异常 | 学龄前模式：离线不可用，显示"网络连接失败，请检查网络"卡通提示；小学/高年级模式：标准离线提示 |
| 孩子端数据加载中 | 学龄前模式：显示卡通加载动画；小学/高年级模式：显示骨架屏 |
