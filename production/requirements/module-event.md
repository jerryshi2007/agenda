## 1. 模块概述

日程管理是家庭日程协作工具的核心模块，负责日程的创建、编辑、删除、查看、打卡等完整生命周期。支持课后活动、日常作息、作业任务三种日程类型，通过统一的"时间槽"模型实现灵活的时间配置。

**核心能力：**

- 三种日程类型（课后活动 / 日常作息 / 作业任务）
- 时间槽模型（7 天独立配置，支持快速填充 + 逐天微调）
- 完整的 CRUD 流程（创建 / 编辑 / 删除 / 查看）
- 重复日程管理（单次修改 / 全部修改 / 临时取消）
- 打卡确认（前端统一显示"已完成"，后台记录打卡人）
- 与日历视图的深度集成（月 / 周 / 日三视图）

## 2. 日程类型设计

### 2.1 类型概览

三种类型保持独立，时间模型统一使用时间槽（7 天独立配置）。每种类型的内置行为（打卡语义、提醒策略、逾期处理）不同，无需用户手动配置。

| 类型 | 典型场景 | 时间模型 | 打卡语义 | 提醒策略 | 逾期处理 |
|------|---------|---------|---------|---------|---------|
| **课后活动** | 钢琴课、游泳课、补习班 | 时间槽，周重复 | 确认到场 | 提前提醒（默认 30 分钟） | 过期显示"已结束" |
| **日常作息** | 起床、练琴、阅读、睡觉 | 时间槽，周重复 | 每日完成打卡 | 按时提醒 | 当日未打卡标记"未完成" |
| **作业任务** | 学校作业、学习任务 | 截止日期，不重复 | 完成即归档 | 截止前提醒 | 逾期标记"逾期未完成" |

### 2.2 课后活动

**适用场景**：有固定时间段的课外活动，通常每周重复。

| 字段 | 说明 | 必填 |
|------|------|:--:|
| 活动名称 | 如"钢琴课" | 是 |
| 时间槽 | 7 天独立配置，每天可设开始/结束时间 | 是 |
| 地点 | 如"少年宫 3 楼钢琴教室" | 否 |
| 备注 | 如"记得带琴谱" | 否 |
| 关联孩子 | 可多选，一次创建关联多个孩子 | 是 |
| 重复结束日期 | 可选，不设则无限重复 | 否 |

**示例**：钢琴课，周二 16:00-17:00、周四 16:00-17:00，少年宫 3 楼，关联"小明"，重复至 2026-12-31。

### 2.3 日常作息

**适用场景**：每日例行事项，每周各天时间可能不同。

| 字段 | 说明 | 必填 |
|------|------|:--:|
| 作息名称 | 如"练琴""起床" | 是 |
| 时间槽 | 7 天独立配置，每天可设开始/结束时间 | 是 |
| 备注 | 如"练琴至少 30 分钟" | 否 |
| 关联孩子 | 可多选，一次创建关联多个孩子 | 是 |
| 重复结束日期 | 可选，不设则无限重复 | 否 |

**示例**：作息"练琴"，周一~周五 16:00-16:30、周三 17:00-17:30（下课晚）、周六~周日 10:00-11:00（周末练久一点），关联"小明"。

### 2.4 作业任务

**适用场景**：一次性任务，有截止日期，完成后归档。

| 字段 | 说明 | 必填 |
|------|------|:--:|
| 任务名称 | 如"数学练习册 P32-35" | 是 |
| 截止日期 | 任务必须在此日期前完成 | 是 |
| 建议时间段 | 建议完成的时间段，如"下午 15:00-16:00" | 否 |
| 备注 | 如"做完后拍照发群里" | 否 |
| 关联孩子 | 可多选，一次创建关联多个孩子 | 是 |

**示例**：数学练习册 P32-35，截止 10 月 27 日（周五），建议下午 15:00-16:00 完成，关联"小明"。

### 2.5 类型差异总结

课后活动与日常作息的核心差异在于行为语义层，而非时间模型：

| 差异点 | 课后活动 | 日常作息 |
|--------|---------|---------|
| 地点字段 | 有 | 无 |
| 打卡语义 | 确认到场 | 完成打卡 |
| 提醒策略 | 提前提醒 | 按时提醒 |
| 逾期处理 | 显示"已结束" | 标记"未完成" |

## 3. 时间槽模型

### 3.1 模型定义

三种类型中，课后活动和日常作息使用统一的时间槽模型，作业任务使用截止日期模型。

**时间槽**：一个日程对应 7 个独立的时间槽（周一至周日），每天可配置不同的开始时间、结束时间，或设为"无安排"（跳过该天）。

### 3.2 创建流程（快速填充 + 逐天微调）

采用方案 B：用户先选择星期几和默认时间，系统自动填充对应天，用户可逐天微调。

```
步骤 1：选择星期几
  ☑一  ☑二  ☐三  ☑四  ☐五  ☐六  ☐日

步骤 2：设置默认时间
  [16:00] - [17:00]

步骤 3：系统自动填充
  ┌────────────────────────────────────┐
  │ 周一  16:00-17:00        [微调 >]  │
  │ 周二  16:00-17:00        [微调 >]  │
  │ 周四  16:00-17:00        [微调 >]  │
  └────────────────────────────────────┘

步骤 4（可选）：点击"微调"展开某天，修改时间
  ┌────────────────────────────────────┐
  │ 周三  17:00-17:30  ← 手动修改后    │
  └────────────────────────────────────┘
```

**设计原则**：
- 底层数据始终是时间槽，不存在"快速模式"和"高级模式"的数据不一致
- 90% 场景：选星期几 + 填默认时间，一键完成
- 10% 场景：展开逐天微调
- 模板保存时存储完整时间槽，还原时保留已修改的天

### 3.3 作业任务的时间模型

作业任务不使用时间槽，使用"截止日期 + 可选建议时间段"：

- 截止日期：必填，单日选择
- 建议时间段：可选，用于在日历上示意性展示

## 4. 创建流程

### 4.1 流程步骤

```
选孩子 → 选类型 → 填字段 → 确认创建
```

**第 1 步：选择孩子**

- 展示家庭中所有孩子列表，支持多选
- 如果只有一个孩子，可预选但用户仍可取消
- 选中的孩子会在后续步骤中作为日程的关联对象

**第 2 步：选择类型**

- 三个类型卡片：课后活动 / 日常作息 / 作业任务
- 下方提供"从模板创建"入口

**第 3 步：填写日程信息**

- 根据所选类型展示对应字段（见第 2 节）
- 课后活动 / 日常作息：展示时间槽配置（快速填充 + 微调）
- 作业任务：展示截止日期 + 可选建议时间段

**第 4 步：确认创建**

- 预览日程摘要信息
- 点击"创建"提交，返回日历视图

### 4.2 设计决策

- **先选孩子再填内容**：更符合家长心智模型——"先确定给谁安排，再想安排什么"
- **支持多选孩子**：一次创建关联多个孩子，打卡记录各自独立

## 5. 编辑流程

### 5.1 编辑入口

- 日历视图点击日程卡片 → 进入详情页 → 点击"编辑"
- 详情页内直接切换编辑模式

### 5.2 编辑范围切换

对于重复日程（课后活动、日常作息），编辑页顶部提供分段开关：

```
┌──────────────────────────────────────┐
│  ┌──────────────┬──────────────────┐ │
│  │ ● 仅本次      │  全部日程         │ │
│  └──────────────┴──────────────────┘ │
│                                      │
│  活动名称 [钢琴课________________]    │
│  ...                                 │
└──────────────────────────────────────┘
```

**设计决策：**

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 默认选中 | 仅本次 | 安全优先，避免误改整个序列 |
| 切换不丢数据 | 是 | 用户填了一半切换时，已填内容保留 |
| "全部"修改范围 | 所有未来实例（含当前） | 历史已过去的实例不变 |
| 作业任务 | 不显示此切换 | 一次性任务无序列概念 |

## 6. 删除流程

### 6.1 删除入口

日程详情页底部"删除"按钮（红色/警示色），点击弹出确认弹窗。

### 6.2 确认弹窗

**重复日程（课后活动、日常作息）：**

```
┌────────────────────────────────────┐
│  删除"钢琴课"                      │
│                                    │
│  该日程为重复日程，请选择删除范围：   │
│                                    │
│  ● 仅删除本次（10月25日 周四）      │
│  ○ 删除此日期及之后所有            │
│                                    │
│  ⚠ 删除后无法恢复                   │
│                                    │
│       [取消]      [确认删除]        │
└────────────────────────────────────┘
```

**作业任务（一次性）：**

```
┌────────────────────────────────────┐
│  删除"数学练习册 P32-35"            │
│  删除后无法恢复，确定删除？          │
│                                    │
│       [取消]      [确认删除]        │
└────────────────────────────────────┘
```

### 6.3 设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 默认选中 | 仅删除本次 | 安全第一，防止误删整个序列 |
| 选项数量 | 两个（仅本次 / 本次及之后） | "全部"="本次及之后"，历史实例始终保留 |
| 历史实例 | 保留，打卡记录不丢失 | 数据完整性 |
| 作业任务 | 直接确认删除 | 无重复概念 |

## 7. 临时取消功能

### 7.1 独立功能设计

"临时取消"是高频场景（孩子生病、老师请假、临时有事），提供独立按钮，不走编辑流程。

### 7.2 交互流程

```
日程详情页
┌──────────────────────────────────┐
│  [编辑]  [取消本次]  [删除]       │
└──────────────────────────────────┘

点击"取消本次" → 确认弹窗：
┌──────────────────────────────────┐
│  取消本次钢琴课？                 │
│  10月25日（周四）的钢琴课将取消，  │
│  后续日程不受影响。               │
│                                  │
│       [算了]      [确认取消]      │
└──────────────────────────────────┘
```

### 7.3 日历显示

取消后，日程卡片显示为灰色文字 + 删除线，标注"已取消"：

```
┌──────┐
│ 钢琴课 │  ← 正常日程
│16:00 │
└──────┘
┌──────┐
│~~钢琴课~~│  ← 已取消日程
│ 已取消 │    灰色文字 + 删除线
└──────┘
```

### 7.4 恢复操作

已取消的日程详情页，原"取消本次"按钮变为"恢复本次"，点击立即恢复为正常日程。

### 7.5 适用范围

- 仅适用于重复日程（课后活动、日常作息）的单个实例
- 作业任务不显示此按钮（一次性任务可直接删除）

## 8. 日程详情页

### 8.1 布局结构

```
┌──────────────────────────────────────┐
│  ← 返回          钢琴课               │  顶部导航
│                  课后活动             │  类型标签
├──────────────────────────────────────┤
│                                      │
│  状态：已完成 ✓ / 未完成 ○ /          │  打卡状态区
│        已取消 — / 逾期 ✗             │
│                                      │
│  ── 基本信息 ──                       │
│  日期      10月25日 周四              │
│  时间      16:00 - 17:00             │
│  地点      少年宫3楼钢琴教室          │  ← 仅课后活动显示
│  关联孩子  小明                      │
│  备注      记得带琴谱                 │
│                                      │
│  ── 重复信息 ──                       │  ← 仅重复日程显示
│  重复规则  每周二、周四               │
│  结束日期  2026年12月31日             │
│                                      │
│  ── 打卡记录 ──                       │
│  小明      已完成  17:05              │
│                                      │
├──────────────────────────────────────┤
│                                      │
│  [打卡确认]  [编辑]  [取消本次]  [删除] │  操作区
│                                      │
└──────────────────────────────────────┘
```

### 8.2 三种类型的差异

| 区域 | 课后活动 | 日常作息 | 作业任务 |
|------|:--:|:--:|:--:|
| 地点 | 显示 | 不显示 | 不显示 |
| 时间 | 时间段 | 时间段 | 截止日期 + 建议时间段 |
| 重复信息 | 显示 | 显示 | 不显示 |
| 打卡按钮文案 | "确认到场" | "完成打卡" | "标记完成" |
| 取消本次按钮 | 显示 | 显示 | 不显示（一次性） |

### 8.3 家长端 vs 孩子端

| 区域 | 家长端 | 孩子端 |
|------|--------|--------|
| 基本信息 | 全部显示 | 全部显示 |
| 关联孩子 | 显示所有关联孩子 | 仅显示自己 |
| 重复信息 | 显示 | 显示 |
| 打卡记录 | 显示所有孩子的打卡状态 | 仅显示自己的打卡状态 |
| 编辑按钮 | 显示 | 隐藏（除高年级自主添加的日程） |
| 删除按钮 | 显示 | 隐藏 |
| 取消本次按钮 | 显示 | 隐藏 |
| 打卡按钮 | 可帮孩子打卡 | 可给自己打卡 |

### 8.4 打卡按钮交互逻辑

| 当前状态 | 按钮显示 | 点击后 |
|---------|---------|--------|
| 未完成 | [打卡确认] | 变为"已完成" |
| 已完成 | [撤销打卡] | 变为"未完成" |
| 已取消 | 无打卡按钮 | 需先恢复 |
| 已逾期 | 无打卡按钮 | 显示"已逾期" |

### 8.5 打卡记录显示

- 前端统一显示"已完成"，不区分打卡人
- 后台记录真实打卡人（家长本人 / 孩子本人）
- 家长代打卡后，孩子端显示为"已完成"，无额外标记

## 9. 与日历视图的关系

### 9.1 视图概览

日历视图支持月 / 周 / 日三种视图，通过顶部分段控件切换：

```
┌──────────────────────────────────────┐
│  ← 2026年10月                    今天 │
├──────────────────────────────────────┤
│  [  月  ]  [  周  ]  [  日  ]        │
├──────────────────────────────────────┤
│        （日历内容区域）                │
└──────────────────────────────────────┘
```

### 9.2 颜色区分

**按日程类型着色**（非按孩子）：

| 类型 | 颜色 | 用途 |
|------|------|------|
| 课后活动 | 蓝色 | 卡片颜色条、色点 |
| 日常作息 | 绿色 | 卡片颜色条、色点 |
| 作业任务 | 橙色 | 卡片颜色条、色点 |

孩子归属通过卡片上的头像/名字标签区分，不通过颜色区分。

### 9.3 月视图

**展示形式**：传统日历网格（7 列 x 5-6 行）

**信息密度**：仅日期数字 + 色点（≤3 个，超出显示"+N"）

```
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│  一   │  二   │  三   │  四   │  五   │  六   │  日   │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│  5   │  6   │  7   │  8   │  9   │ 10   │ 11   │
│ ●●○  │ ○○   │ ●●   │      │ ●●○  │ ●    │      │
└──────┴──────┴──────┴──────┴──────┴──────┴──────┘
```

- 今天（today）日期数字高亮显示
- 非当月日期灰色显示
- 点击某天 → 跳转该天日视图

### 9.4 周视图

**展示形式**：7 列网格，按时间纵向排列

**卡片信息**：颜色条 + 时间 + 名称 + 孩子头像 + 完成状态图标

| 信息 | 显示 |
|------|:--:|
| 颜色条（类型区分） | 是 |
| 时间 | 是 |
| 名称 | 是 |
| 孩子头像 | 仅头像 |
| 完成状态 | 图标 |
| 类型标签 | 否 |
| 地点 | 否 |
| 备注 | 否 |

### 9.5 日视图

**展示形式**：时间线布局，按时间纵轴排列

**卡片信息**：完整信息展示

| 信息 | 显示 |
|------|:--:|
| 颜色条（类型区分） | 是 |
| 时间 | 是 |
| 名称 | 是 |
| 孩子头像/名 | 头像 + 名 |
| 完成状态 | 图标 + 文字 |
| 类型标签 | 是 |
| 地点 | 是 |
| 备注 | 是 |

### 9.6 三视图信息密度对比

| 信息 | 月视图 | 周视图 | 日视图 |
|------|:--:|:--:|:--:|
| 颜色条/点 | 色点 | 颜色条 | 颜色条 |
| 时间 | -- | 显示 | 显示 |
| 名称 | -- | 显示 | 显示 |
| 孩子头像 | -- | 仅头像 | 头像+名 |
| 完成状态 | -- | 图标 | 图标+文字 |
| 类型标签 | -- | -- | 显示 |
| 地点 | -- | -- | 显示 |
| 备注 | -- | -- | 显示 |
| 交互 | 点击跳日视图 | 点击进详情 | 点击进详情 |

### 9.7 默认视图

| 角色 | 默认视图 | 理由 |
|------|:--:|------|
| 家长端 | 周视图 | 需要统筹一周安排，信息密度适中 |
| 孩子端 | 日视图 | 只需关注"今天要做什么"，最直观 |

### 9.8 筛选逻辑

- **按孩子筛选**：顶部筛选栏，支持单选孩子或"全部孩子"
- **按类型筛选**：支持按课后活动 / 日常作息 / 作业任务筛选
- **默认显示**：全部孩子 + 全部类型
- 筛选条件在所有视图（月/周/日）中保持一致

## 13. GWT 用户故事与验收标准

> 本节为 2026-08-08 补充的 Given-When-Then 结构化用户故事与验收标准，与上方各章节的详细设计一一对应。优先级采用 Must/Should/Could 三级。本节中 US 除显式标注 Should 者外，其余默认 Must。

### 13.1 日程创建

#### US-EVT-01：家长为孩子创建课后活动日程 [Must]

- **Given** 家长已登录，当前在"选孩子"步骤
- **When** 选择 1 个或多个孩子 → 选择"课后活动"类型 → 填写活动名称（必填）、选择星期几、设置默认时间段 → 填写选填字段（地点、备注）→ 点击"创建"
- **Then** 系统生成日程，按选中的星期几和时间槽在日历上展示，关联所选孩子。返回日历视图，新日程可见。
- **Given** 家长在"选孩子"步骤未选择任何孩子
- **When** 点击"下一步"
- **Then** 系统提示"请至少选择一个孩子"，不进入下一步

#### US-EVT-02：家长为孩子创建日常作息日程 [Must]

- **Given** 家长已登录，已选择孩子，当前在"选择类型"步骤
- **When** 选择"日常作息"类型 → 填写作息名称（必填）→ 选择星期几、设置默认时间段 → 可选逐天微调 → 点击"创建"
- **Then** 系统生成作息日程，按时间槽在日历上展示。创建结果与课后活动流程一致。
- **Given** 作息名称为空
- **When** 点击"创建"
- **Then** 系统提示"请输入作息名称"，阻止提交

#### US-EVT-03：家长为孩子创建作业任务 [Must]

- **Given** 家长已登录，已选择孩子和"作业任务"类型
- **When** 填写任务名称（必填）→ 选择截止日期（必填）→ 可选填建议时间段和备注 → 点击"创建"
- **Then** 系统生成作业任务，在日历截止日期当天展示。不生成重复实例。
- **Given** 截止日期早于今天
- **When** 选择截止日期
- **Then** 系统提示"截止日期不能早于今天"，阻止提交（或至少给出警告）

#### US-EVT-04：家长通过模板快速创建日程 [Should]

> 优先级说明：模板模块已完成，但日程模块对模板的对接属于体验增强而非 MVP 核心流程。若第一期资源允许、模板模块已完成联调前提满足，可交付为 Must。

- **Given** 家长已登录，在创建流程"选择类型"步骤
- **When** 点击"从模板创建"→ 选择一个模板（预设或自定义）→ 模板字段自动填充 → 按需微调 → 指定关联孩子 → 确认创建
- **Then** 系统按模板生成日程，直接展示在日历上。创建流程比手工填写少 1-2 步。
- **Given** 所选模板中的孩子与当前家庭孩子不匹配
- **When** 点击"从模板创建"
- **Then** 系统自动清理模板中的孩子关联，要求家长重新指定

#### US-EVT-05：日程冲突检测 [Must]

- **Given** 家长正在创建日程，填写的时间段与同一孩子的已有日程存在时间重叠
- **When** 点击"创建"
- **Then** 系统弹出软提示"该时段与 [已有日程名称] 存在时间重叠，是否继续创建？"，用户可选择"继续创建"或"返回修改"。选择"继续创建"则正常创建（不阻止）；选择"返回修改"则回到编辑页。
- **Given** 时间重叠但目标孩子不同
- **When** 点击"创建"
- **Then** 不触发冲突检测（仅针对同一孩子检测）

### 13.2 日程编辑

#### US-EVT-06：家长编辑日程（仅本次） [Must]

- **Given** 家长在重复日程（如钢琴课）的详情页，点击"编辑"，分段开关默认选中"仅本次"
- **When** 修改活动名称为"钢琴课补课"，点击"保存"
- **Then** 仅当天该实例的名称变为"钢琴课补课"，其他实例不受影响
- **Given** 家长在"仅本次"模式下填了一半，切换到"全部日程"
- **When** 切换分段开关
- **Then** 已填写的内容保留不丢失，编辑范围切换为全部未来实例
- **Given** 今天的日程实例已被打卡（状态为"已完成"），家长在详情页点击"编辑"
- **When** 修改非打卡相关字段（如地点、备注），点击"保存"
- **Then** 编辑成功保存，打卡记录保持不变（不因编辑而重置打卡状态）。若修改了类型字段（如从"课后活动"变为"日常作息"），打卡记录保持有效但打卡语义随之变更（如"确认到场"变为"完成打卡"）。

#### US-EVT-07：家长编辑日程（全部未来实例） [Must]

- **Given** 家长在日程详情页，点击"编辑"，切换到"全部日程"
- **When** 修改时间槽（如将周四 16:00-17:00 改为 17:00-18:00），点击"保存"
- **Then** 当前实例及所有未来实例的时间槽均更新为 17:00-18:00，历史已过去的实例不变
- **Given** 该日程无未来实例（重复已结束）
- **When** 切换到"全部日程"并保存
- **Then** 系统提示"该日程无未来实例，仅修改当前实例"，实际执行"仅本次"修改

#### US-EVT-08：编辑作业任务 [Must]

- **Given** 家长在作业任务详情页，点击"编辑"
- **When** 修改截止日期，点击"保存"
- **Then** 截止日期更新，日历上该任务移动到新日期
- **Given** 作业任务编辑时不显示"仅本次/全部"开关
- **When** 家长进入编辑页
- **Then** 不显示分段开关（一次性任务无序列概念）

### 13.3 日程删除

#### US-EVT-09：家长删除日程（仅本次） [Must]

- **Given** 家长在重复日程详情页，点击"删除"
- **When** 弹出确认弹窗，默认选中"仅删除本次"→ 点击"确认删除"
- **Then** 仅当天该实例被删除。日历上该时间段不再显示此日程。历史实例和未来实例不受影响。历史打卡记录保留。
- **Given** 家长点击"删除"后选择"取消"
- **When** 点击弹窗中"取消"按钮
- **Then** 弹窗关闭，日程不受影响

#### US-EVT-10：家长删除日程（本次及之后所有） [Must]

- **Given** 家长在重复日程详情页，点击"删除"
- **When** 弹出确认弹窗，选择"删除此日期及之后所有"→ 点击"确认删除"
- **Then** 当天及所有未来实例全部删除，历史实例保留，历史打卡记录保留
- **Given** 日程仅剩最后一个未来实例
- **When** 选择"删除此日期及之后所有"→ 确认
- **Then** 仅删除当前实例（等价于"仅本次"），不会产生"删除未来 0 个实例"的歧义

#### US-EVT-11：家长删除一次性作业任务 [Must]

- **Given** 家长在作业任务详情页，点击"删除"
- **When** 弹出简单确认弹窗（无范围选择）→ 点击"确认删除"
- **Then** 该任务被删除，打卡记录保留
- **Given** 家长在作业任务详情页，点击"删除"后弹出确认弹窗
- **When** 点击弹窗中"取消"按钮
- **Then** 弹窗关闭，任务不受影响，保持在详情页

### 13.4 临时取消与恢复

#### US-EVT-12：家长取消本次日程 [Must]

- **Given** 家长在重复日程详情页
- **When** 点击"取消本次"按钮 → 弹出确认弹窗 → 点击"确认取消"
- **Then** 当天该实例状态变为"已取消"，日历上显示灰色文字 + 删除线，标注"已取消"。后续日程不受影响。
- **Given** 作业任务详情页
- **When** 家长查看详情
- **Then** 不显示"取消本次"按钮（一次性任务可直接删除）

#### US-EVT-13：家长恢复已取消的日程 [Must]

- **Given** 已取消的日程实例详情页，原"取消本次"按钮已变为"恢复本次"
- **When** 点击"恢复本次"
- **Then** 该实例立即恢复为"未完成"状态，日历上恢复正常显示。无需二次确认。
- **Given** 该日程已被整体删除（非临时取消），用户尝试通过历史链接或推送消息访问该日程详情页
- **When** 客户端请求详情数据
- **Then** 服务端返回"日程不存在或已删除"，前端显示"该日程已被删除"，不展示详情页，不显示"恢复本次"按钮

### 13.5 打卡确认

#### US-EVT-14：家长/孩子在详情页打卡 [Must]

- **Given** 用户（家长或孩子）在日程详情页，日程状态为"未完成"且未逾期
- **When** 点击"打卡确认"（课后活动）/ "完成打卡"（日常作息）/ "标记完成"（作业任务）
- **Then** 日程状态变为"已完成"，显示绿色勾号 ✓。后台记录打卡人 ID 和打卡时间。
- **Given** 日程状态已是"已完成"
- **When** 用户查看详情
- **Then** 打卡按钮变为"撤销打卡"，点击后状态恢复为"未完成"，后台记录撤销操作
- **Given** 日程状态为"已取消"
- **When** 用户查看详情
- **Then** 不显示打卡按钮

#### US-EVT-15：日历视图快捷打卡 [Should]

- **Given** 用户在日视图或周视图中看到未完成的日程卡片
- **When** 点击卡片上的快捷打卡图标/按钮
- **Then** 日程状态立即变为"已完成"，卡片显示绿色勾号，无需进入详情页
- **Given** 用户在月视图
- **When** 查看某个日期
- **Then** 不提供快捷打卡入口（月视图仅展示色点，需进入日视图后打卡）

> 注：打卡时间窗口、逾期判定、结算规则等详细逻辑由打卡与统计模块文档定义，日程模块仅定义打卡入口和前端交互。快捷打卡按钮的可用性判断（如时间窗口外是否灰显）复用打卡模块规则。

### 13.6 日历视图

#### US-EVT-16：月视图展示与交互 [Must]

- **Given** 家长已登录，在日历页面
- **When** 切换到月视图
- **Then** 显示传统日历网格（7 列 x 5-6 行）。每个日期格显示日期数字 + 最多 3 个色点（按日程类型着色），超出显示"+N"。今天日期高亮。非当月日期灰色。点击某天 → 跳转该天日视图。
- **Given** 月视图中某个日期无任何日程
- **When** 查看该日期格
- **Then** 仅显示日期数字，无任何色点

#### US-EVT-17：周视图展示与交互 [Must]

- **Given** 家长已登录，在日历页面
- **When** 切换到周视图
- **Then** 7 列网格按时间纵向排列。每个日程卡片显示：颜色条 + 时间 + 名称 + 孩子头像 + 完成状态图标。点击卡片进入详情页。
- **Given** 周视图中某天无日程
- **When** 查看该天列
- **Then** 显示空列，无任何日程卡片

#### US-EVT-18：日视图展示与交互 [Must]

- **Given** 家长已登录，在日历页面
- **When** 切换到日视图
- **Then** 时间线布局，按时间纵轴排列。每个日程卡片显示完整信息：颜色条 + 时间 + 名称 + 孩子头像+名 + 完成状态图标+文字 + 类型标签 + 地点 + 备注。点击卡片进入详情页。
- **Given** 当天无任何日程
- **When** 查看日视图
- **Then** 显示空状态提示"今天没有日程安排"，并提供"创建日程"快捷入口

#### US-EVT-19：视图筛选 [Must]

- **Given** 用户在日历视图（月/周/日任意）
- **When** 在顶部筛选栏选择特定孩子（如"小明"）
- **Then** 日历仅显示该孩子的日程。筛选条件在所有视图间保持一致。
- **Given** 用户在筛选栏选择特定日程类型（如"课后活动"）
- **When** 切换筛选
- **Then** 日历仅显示该类型的日程
- **Given** 筛选后某天无匹配日程
- **When** 查看该天
- **Then** 显示空状态"该筛选条件下无日程"

### 13.7 日程详情页

#### US-EVT-20：查看日程详情（正常状态） [Must]

- **Given** 用户点击日历上的日程卡片
- **When** 进入日程详情页
- **Then** 显示完整的日程信息：基本信息（日期/时间/地点/孩子/备注）、重复信息（重复规则/结束日期，仅重复日程）、打卡记录（关联孩子的打卡状态）、操作按钮（打卡确认/编辑/取消本次/删除）
- **Given** 详情页中的日程数据在显示前已被其他用户修改
- **When** 用户查看
- **Then** 显示最新数据（每次进入详情页时从服务端拉取最新数据，不依赖缓存）

## 14. 边界与异常覆盖

以下覆盖空值、越界、并发、失败回退等异常场景，与上方用户故事中的异常路径互补。

### 14.1 输入边界

| # | 场景 | 边界条件 | 预期行为 |
|---|------|---------|---------|
| BE-01 | 日程名称过长 | 超过 50 字符 | 前端限制输入长度 ≤ 50 字符；后端校验，超出则返回 400 + 错误信息 |
| BE-02 | 日程名称为纯空格 | 输入仅含空白字符 | 提交时 trim 后判断，若为空则提示"请输入有效名称" |
| BE-03 | 备注超长 | 超过 500 字符 | 前端限制 ≤ 500 字符；后端同样校验 |
| BE-04 | 时间槽开始时间晚于结束时间 | 如 18:00 - 16:00 | 前端实时校验，提醒"开始时间不能晚于结束时间"，阻止提交 |
| BE-05 | 一周 7 天全部设为"无安排" | 所有天均未勾选 | 提交时校验，提示"请至少选择一天"，阻止提交 |
| BE-06 | 关联孩子超过家庭孩子数 | 一次选择超过实际孩子数 | 下拉/多选列表中仅显示家庭中实际存在的孩子 |
| BE-07 | 重复结束日期早于今天 | 如结束日期设为昨天 | 校验并提示"结束日期不能早于今天" |

### 14.2 空状态

| # | 场景 | 预期行为 |
|---|------|---------|
| BE-08 | 家庭中无孩子 | 创建日程时"选孩子"步骤显示空状态提示"请先添加孩子"，并提供跳转"家庭管理"的入口 |
| BE-09 | 日历视图无任何日程 | 显示空状态插画 + 文案"还没有日程，点击创建第一个日程吧"，并提供"创建日程"按钮 |
| BE-10 | 筛选后无匹配日程 | 显示"该筛选条件下无日程"，建议调整筛选条件 |

## 15. 优先级分级

以下按功能域进行 Must/Should/Could 分级，作为研发排期和 MVP 取舍依据。功能项与 US 的映射见各 US 标题后缀标注。

### Must（第一期必须交付）

| 功能 | 说明 | 关联 US |
|------|------|------|
| 日程创建（三种类型） | 课后活动、日常作息、作业任务的完整创建流程 | US-EVT-01, 02, 03 |
| 时间槽模型 | 快速填充 + 逐天微调，7 天独立配置 | US-EVT-01, 02 |
| 日程编辑（仅本次 / 全部） | 分段开关，默认"仅本次" | US-EVT-06, 07, 08 |
| 日程删除（仅本次 / 本次及之后） | 确认弹窗，历史保留 | US-EVT-09, 10, 11 |
| 临时取消与恢复 | 独立按钮，灰色+删除线，即刻恢复 | US-EVT-12, 13 |
| 详情页打卡确认 | 家长和孩子均可打卡/撤销打卡 | US-EVT-14 |
| 日历月/周/日三视图 | 三视图切换，颜色按类型区分 | US-EVT-16, 17, 18 |
| 按孩子、按类型筛选 | 筛选条件跨视图保持 | US-EVT-19 |
| 日程冲突检测（软提示） | 检测 + 弹提醒，不阻止创建 | US-EVT-05 |
| 空状态处理 | 无日程、无孩子的友好提示 | BE-08 ~ BE-11 |
| 输入校验 | 名称必填/长度限制、时间合法性、至少一天 | BE-01 ~ BE-07 |
