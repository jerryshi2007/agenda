## 1. 模块概述

日程管理是家庭日程协作工具的核心模块，负责日程的创建、编辑、删除、查看、打卡等完整生命周期。支持课后活动、日常作息、作业任务三种日程类型，通过统一的"时间槽"模型实现灵活的时间配置。

**核心能力：**

- 三种日程类型（课后活动 / 日常作息 / 作业任务）
- 时间槽模型（7 天独立配置，支持快速填充 + 逐天微调）
- 完整的 CRUD 流程（创建 / 编辑 / 删除 / 查看）
- 重复日程管理（单次修改 / 全部修改 / 临时取消）
- 打卡确认（前端统一显示"已完成"，后台记录打卡人）
- 与日历视图的深度集成（月 / 周 / 日三视图）

## 2. 日程类型设计

### 2.1 类型概览

三种类型保持独立，时间模型统一使用时间槽（7 天独立配置）。每种类型的内置行为（打卡语义、提醒策略、逾期处理）不同，无需用户手动配置。

| 类型 | 典型场景 | 时间模型 | 打卡语义 | 提醒策略 | 逾期处理 |
|------|---------|---------|---------|---------|---------|
| **课后活动** | 钢琴课、游泳课、补习班 | 时间槽，周重复 | 确认到场 | 提前提醒（默认 30 分钟） | 过期显示"已结束" |
| **日常作息** | 起床、练琴、阅读、睡觉 | 时间槽，周重复 | 每日完成打卡 | 按时提醒 | 当日未打卡标记"未完成" |
| **作业任务** | 学校作业、学习任务 | 截止日期，不重复 | 完成即归档 | 截止前提醒 | 逾期标记"逾期未完成" |

### 2.2 课后活动

**适用场景**：有固定时间段的课外活动，通常每周重复。

| 字段 | 说明 | 必填 |
|------|------|:--:|
| 活动名称 | 如"钢琴课" | 是 |
| 时间槽 | 7 天独立配置，每天可设开始/结束时间 | 是 |
| 地点 | 如"少年宫 3 楼钢琴教室" | 否 |
| 备注 | 如"记得带琴谱" | 否 |
| 关联孩子 | 可多选，一次创建关联多个孩子 | 是 |
| 重复结束日期 | 可选，不设则无限重复 | 否 |

**示例**：钢琴课，周二 16:00-17:00、周四 16:00-17:00，少年宫 3 楼，关联"小明"，重复至 2026-12-31。

### 2.3 日常作息

**适用场景**：每日例行事项，每周各天时间可能不同。

| 字段 | 说明 | 必填 |
|------|------|:--:|
| 作息名称 | 如"练琴""起床" | 是 |
| 时间槽 | 7 天独立配置，每天可设开始/结束时间 | 是 |
| 备注 | 如"练琴至少 30 分钟" | 否 |
| 关联孩子 | 可多选，一次创建关联多个孩子 | 是 |
| 重复结束日期 | 可选，不设则无限重复 | 否 |

**示例**：作息"练琴"，周一~周五 16:00-16:30、周三 17:00-17:30（下课晚）、周六~周日 10:00-11:00（周末练久一点），关联"小明"。

### 2.4 作业任务

**适用场景**：一次性任务，有截止日期，完成后归档。

| 字段 | 说明 | 必填 |
|------|------|:--:|
| 任务名称 | 如"数学练习册 P32-35" | 是 |
| 截止日期 | 任务必须在此日期前完成 | 是 |
| 建议时间段 | 建议完成的时间段，如"下午 15:00-16:00" | 否 |
| 备注 | 如"做完后拍照发群里" | 否 |
| 关联孩子 | 可多选，一次创建关联多个孩子 | 是 |

**示例**：数学练习册 P32-35，截止 10 月 27 日（周五），建议下午 15:00-16:00 完成，关联"小明"。

### 2.5 类型差异总结

课后活动与日常作息的核心差异在于行为语义层，而非时间模型：

| 差异点 | 课后活动 | 日常作息 |
|--------|---------|---------|
| 地点字段 | 有 | 无 |
| 打卡语义 | 确认到场 | 完成打卡 |
| 提醒策略 | 提前提醒 | 按时提醒 |
| 逾期处理 | 显示"已结束" | 标记"未完成" |

## 3. 时间槽模型

### 3.1 模型定义

三种类型中，课后活动和日常作息使用统一的时间槽模型，作业任务使用截止日期模型。

**时间槽**：一个日程对应 7 个独立的时间槽（周一至周日），每天可配置不同的开始时间、结束时间，或设为"无安排"（跳过该天）。

### 3.2 创建流程（快速填充 + 逐天微调）

采用方案 B：用户先选择星期几和默认时间，系统自动填充对应天，用户可逐天微调。

```
步骤 1：选择星期几
  ☑一  ☑二  ☐三  ☑四  ☐五  ☐六  ☐日

步骤 2：设置默认时间
  [16:00] - [17:00]

步骤 3：系统自动填充
  ┌────────────────────────────────────┐
  │ 周一  16:00-17:00        [微调 >]  │
  │ 周二  16:00-17:00        [微调 >]  │
  │ 周四  16:00-17:00        [微调 >]  │
  └────────────────────────────────────┘

步骤 4（可选）：点击"微调"展开某天，修改时间
  ┌────────────────────────────────────┐
  │ 周三  17:00-17:30  ← 手动修改后    │
  └────────────────────────────────────┘
```

**设计原则**：
- 底层数据始终是时间槽，不存在"快速模式"和"高级模式"的数据不一致
- 90% 场景：选星期几 + 填默认时间，一键完成
- 10% 场景：展开逐天微调
- 模板保存时存储完整时间槽，还原时保留已修改的天

### 3.3 作业任务的时间模型

作业任务不使用时间槽，使用"截止日期 + 可选建议时间段"：

- 截止日期：必填，单日选择
- 建议时间段：可选，用于在日历上示意性展示

## 4. 创建流程

### 4.1 流程步骤

```
选孩子 → 选类型 → 填字段 → 确认创建
```

**第 1 步：选择孩子**

- 展示家庭中所有孩子列表，支持多选
- 如果只有一个孩子，可预选但用户仍可取消
- 选中的孩子会在后续步骤中作为日程的关联对象

**第 2 步：选择类型**

- 三个类型卡片：课后活动 / 日常作息 / 作业任务
- 下方提供"从模板创建"入口

**第 3 步：填写日程信息**

- 根据所选类型展示对应字段（见第 2 节）
- 课后活动 / 日常作息：展示时间槽配置（快速填充 + 微调）
- 作业任务：展示截止日期 + 可选建议时间段

**第 4 步：确认创建**

- 预览日程摘要信息
- 点击"创建"提交，返回日历视图

### 4.2 设计决策

- **先选孩子再填内容**：更符合家长心智模型——"先确定给谁安排，再想安排什么"
- **支持多选孩子**：一次创建关联多个孩子，打卡记录各自独立

## 5. 编辑流程

### 5.1 编辑入口

- 日历视图点击日程卡片 → 进入详情页 → 点击"编辑"
- 详情页内直接切换编辑模式

### 5.2 编辑范围切换

对于重复日程（课后活动、日常作息），编辑页顶部提供分段开关：

```
┌──────────────────────────────────────┐
│  ┌──────────────┬──────────────────┐ │
│  │ ● 仅本次      │  全部日程         │ │
│  └──────────────┴──────────────────┘ │
│                                      │
│  活动名称 [钢琴课________________]    │
│  ...                                 │
└──────────────────────────────────────┘
```

**设计决策：**

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 默认选中 | 仅本次 | 安全优先，避免误改整个序列 |
| 切换不丢数据 | 是 | 用户填了一半切换时，已填内容保留 |
| "全部"修改范围 | 所有未来实例（含当前） | 历史已过去的实例不变 |
| 作业任务 | 不显示此切换 | 一次性任务无序列概念 |

## 6. 删除流程

### 6.1 删除入口

日程详情页底部"删除"按钮（红色/警示色），点击弹出确认弹窗。

### 6.2 确认弹窗

**重复日程（课后活动、日常作息）：**

```
┌────────────────────────────────────┐
│  删除"钢琴课"                      │
│                                    │
│  该日程为重复日程，请选择删除范围：   │
│                                    │
│  ● 仅删除本次（10月25日 周四）      │
│  ○ 删除此日期及之后所有            │
│                                    │
│  ⚠ 删除后无法恢复                   │
│                                    │
│       [取消]      [确认删除]        │
└────────────────────────────────────┘
```

**作业任务（一次性）：**

```
┌────────────────────────────────────┐
│  删除"数学练习册 P32-35"            │
│  删除后无法恢复，确定删除？          │
│                                    │
│       [取消]      [确认删除]        │
└────────────────────────────────────┘
```

### 6.3 设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 默认选中 | 仅删除本次 | 安全第一，防止误删整个序列 |
| 选项数量 | 两个（仅本次 / 本次及之后） | "全部"="本次及之后"，历史实例始终保留 |
| 历史实例 | 保留，打卡记录不丢失 | 数据完整性 |
| 作业任务 | 直接确认删除 | 无重复概念 |

## 7. 临时取消功能

### 7.1 独立功能设计

"临时取消"是高频场景（孩子生病、老师请假、临时有事），提供独立按钮，不走编辑流程。

### 7.2 交互流程

```
日程详情页
┌──────────────────────────────────┐
│  [编辑]  [取消本次]  [删除]       │
└──────────────────────────────────┘

点击"取消本次" → 确认弹窗：
┌──────────────────────────────────┐
│  取消本次钢琴课？                 │
│  10月25日（周四）的钢琴课将取消，  │
│  后续日程不受影响。               │
│                                  │
│       [算了]      [确认取消]      │
└──────────────────────────────────┘
```

### 7.3 日历显示

取消后，日程卡片显示为灰色文字 + 删除线，标注"已取消"：

```
┌──────┐
│ 钢琴课 │  ← 正常日程
│16:00 │
└──────┘
┌──────┐
│~~钢琴课~~│  ← 已取消日程
│ 已取消 │    灰色文字 + 删除线
└──────┘
```

### 7.4 恢复操作

已取消的日程详情页，原"取消本次"按钮变为"恢复本次"，点击立即恢复为正常日程。

### 7.5 适用范围

- 仅适用于重复日程（课后活动、日常作息）的单个实例
- 作业任务不显示此按钮（一次性任务可直接删除）

## 8. 日程详情页

### 8.1 布局结构

```
┌──────────────────────────────────────┐
│  ← 返回          钢琴课               │  顶部导航
│                  课后活动             │  类型标签
├──────────────────────────────────────┤
│                                      │
│  状态：已完成 ✓ / 未完成 ○ /          │  打卡状态区
│        已取消 — / 逾期 ✗             │
│                                      │
│  ── 基本信息 ──                       │
│  日期      10月25日 周四              │
│  时间      16:00 - 17:00             │
│  地点      少年宫3楼钢琴教室          │  ← 仅课后活动显示
│  关联孩子  小明                      │
│  备注      记得带琴谱                 │
│                                      │
│  ── 重复信息 ──                       │  ← 仅重复日程显示
│  重复规则  每周二、周四               │
│  结束日期  2026年12月31日             │
│                                      │
│  ── 打卡记录 ──                       │
│  小明      已完成  17:05              │
│                                      │
├──────────────────────────────────────┤
│                                      │
│  [打卡确认]  [编辑]  [取消本次]  [删除] │  操作区
│                                      │
└──────────────────────────────────────┘
```

### 8.2 三种类型的差异

| 区域 | 课后活动 | 日常作息 | 作业任务 |
|------|:--:|:--:|:--:|
| 地点 | 显示 | 不显示 | 不显示 |
| 时间 | 时间段 | 时间段 | 截止日期 + 建议时间段 |
| 重复信息 | 显示 | 显示 | 不显示 |
| 打卡按钮文案 | "确认到场" | "完成打卡" | "标记完成" |
| 取消本次按钮 | 显示 | 显示 | 不显示（一次性） |

### 8.3 家长端 vs 孩子端

| 区域 | 家长端 | 孩子端 |
|------|--------|--------|
| 基本信息 | 全部显示 | 全部显示 |
| 关联孩子 | 显示所有关联孩子 | 仅显示自己 |
| 重复信息 | 显示 | 显示 |
| 打卡记录 | 显示所有孩子的打卡状态 | 仅显示自己的打卡状态 |
| 编辑按钮 | 显示 | 隐藏（除高年级自主添加的日程） |
| 删除按钮 | 显示 | 隐藏 |
| 取消本次按钮 | 显示 | 隐藏 |
| 打卡按钮 | 可帮孩子打卡 | 可给自己打卡 |

### 8.4 打卡按钮交互逻辑

| 当前状态 | 按钮显示 | 点击后 |
|---------|---------|--------|
| 未完成 | [打卡确认] | 变为"已完成" |
| 已完成 | [撤销打卡] | 变为"未完成" |
| 已取消 | 无打卡按钮 | 需先恢复 |
| 已逾期 | 无打卡按钮 | 显示"已逾期" |

### 8.5 打卡记录显示

- 前端统一显示"已完成"，不区分打卡人
- 后台记录真实打卡人（家长本人 / 孩子本人）
- 家长代打卡后，孩子端显示为"已完成"，无额外标记

## 9. 与日历视图的关系

### 9.1 视图概览

日历视图支持月 / 周 / 日三种视图，通过顶部分段控件切换：

```
┌──────────────────────────────────────┐
│  ← 2026年10月                    今天 │
├──────────────────────────────────────┤
│  [  月  ]  [  周  ]  [  日  ]        │
├──────────────────────────────────────┤
│        （日历内容区域）                │
└──────────────────────────────────────┘
```

### 9.2 颜色区分

**按日程类型着色**（非按孩子）：

| 类型 | 颜色 | 用途 |
|------|------|------|
| 课后活动 | 蓝色 | 卡片颜色条、色点 |
| 日常作息 | 绿色 | 卡片颜色条、色点 |
| 作业任务 | 橙色 | 卡片颜色条、色点 |

孩子归属通过卡片上的头像/名字标签区分，不通过颜色区分。

### 9.3 月视图

**展示形式**：传统日历网格（7 列 x 5-6 行）

**信息密度**：仅日期数字 + 色点（≤3 个，超出显示"+N"）

```
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│  一   │  二   │  三   │  四   │  五   │  六   │  日   │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│  5   │  6   │  7   │  8   │  9   │ 10   │ 11   │
│ ●●○  │ ○○   │ ●●   │      │ ●●○  │ ●    │      │
└──────┴──────┴──────┴──────┴──────┴──────┴──────┘
```

- 今天（today）日期数字高亮显示
- 非当月日期灰色显示
- 点击某天 → 跳转该天日视图

### 9.4 周视图

**展示形式**：7 列网格，按时间纵向排列

**卡片信息**：颜色条 + 时间 + 名称 + 孩子头像 + 完成状态图标

| 信息 | 显示 |
|------|:--:|
| 颜色条（类型区分） | 是 |
| 时间 | 是 |
| 名称 | 是 |
| 孩子头像 | 仅头像 |
| 完成状态 | 图标 |
| 类型标签 | 否 |
| 地点 | 否 |
| 备注 | 否 |

### 9.5 日视图

**展示形式**：时间线布局，按时间纵轴排列

**卡片信息**：完整信息展示

| 信息 | 显示 |
|------|:--:|
| 颜色条（类型区分） | 是 |
| 时间 | 是 |
| 名称 | 是 |
| 孩子头像/名 | 头像 + 名 |
| 完成状态 | 图标 + 文字 |
| 类型标签 | 是 |
| 地点 | 是 |
| 备注 | 是 |

### 9.6 三视图信息密度对比

| 信息 | 月视图 | 周视图 | 日视图 |
|------|:--:|:--:|:--:|
| 颜色条/点 | 色点 | 颜色条 | 颜色条 |
| 时间 | -- | 显示 | 显示 |
| 名称 | -- | 显示 | 显示 |
| 孩子头像 | -- | 仅头像 | 头像+名 |
| 完成状态 | -- | 图标 | 图标+文字 |
| 类型标签 | -- | -- | 显示 |
| 地点 | -- | -- | 显示 |
| 备注 | -- | -- | 显示 |
| 交互 | 点击跳日视图 | 点击进详情 | 点击进详情 |

### 9.7 默认视图

| 角色 | 默认视图 | 理由 |
|------|:--:|------|
| 家长端 | 周视图 | 需要统筹一周安排，信息密度适中 |
| 孩子端 | 日视图 | 只需关注"今天要做什么"，最直观 |

### 9.8 筛选逻辑

- **按孩子筛选**：顶部筛选栏，支持单选孩子或"全部孩子"
- **按类型筛选**：支持按课后活动 / 日常作息 / 作业任务筛选
- **默认显示**：全部孩子 + 全部类型
- 筛选条件在所有视图（月/周/日）中保持一致

### 9.9 状态视觉呈现

| 状态 | 日历卡片显示 |
|------|-------------|
| 未完成 | 正常颜色，无特殊标记 |
| 已完成 | 绿色勾号 ✓，文字可降低透明度 |
| 已取消 | 灰色文字 + 删除线，标注"已取消" |
| 已逾期 | 红色标记 ✗，标注"已逾期" |

### 9.10 日期跳转

- 顶部标题栏显示当前日期范围，点击弹出日期选择器
- 点击"今天"按钮快速回到当前日期
- 左右滑动切换日/周/月

## 10. 打卡与状态

### 10.1 打卡操作

- 入口：日程详情页底部"打卡确认"按钮；日历视图卡片上快捷打卡按钮
- 操作：点击完成打卡，再次点击撤销打卡
- 记录：后台记录打卡人（家长 / 孩子本人）和打卡时间

### 10.2 状态定义

| 状态 | 条件 | 显示 |
|------|------|------|
| 未完成 | 当前时间 < 日程结束时间，未打卡 | 正常显示 |
| 已完成 | 已打卡 | 绿色 ✓ |
| 已取消 | 被"取消本次"操作 | 灰色 + 删除线 |
| 已逾期 | 超过日程时间仍未打卡 | 红色 ✗ |

### 10.3 打卡记录

- 前端统一显示"已完成"，不区分打卡人
- 后台记录字段：日程 ID、打卡人 ID、打卡时间、操作来源（家长端/孩子端）

## 11. 模板系统

### 11.1 与日程管理的关系

模板系统是日程创建的快捷入口，核心逻辑：

- 预设模板：系统内置常用模板
- 自定义模板：家长将已有日程保存为模板，或从零创建
- 模板存储完整时间槽数据，使用时可进一步微调
- 创建流程：选择模板 → 填入姓名/日期参数 → 关联孩子 → 一键生成

详细设计见模板系统模块文档（待创建）。
