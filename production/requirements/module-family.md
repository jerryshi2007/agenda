# 家庭管理模块 · 产品需求文档

> 版本：v1.0 | 日期：2026-08-03 | 状态：草案
>
> 所属产品：[家庭日程协作工具](index.md)
>
> 本文档为 `index.md` 的模块化拆分，聚焦家庭管理模块的详细设计。其他模块设计见对应模块文档。

---

## 1. 模块概述

家庭管理是用户进入系统后的第一个模块，负责家庭的创建、成员邀请、角色管理、孩子设置、多家庭切换、退出/解散等完整生命周期。

**核心能力：**

- 家庭创建（创建者自选角色：家长或孩子）
- 双轨邀请机制（家长：微信分享卡片/小程序码；孩子：6 位邀请码）
- 成员列表与角色管理（角色在加入时确定，不可更改）
- 孩子展示模式设置（学龄前 / 小学 / 高年级）
- 多家庭切换（每个家庭独立记住上次状态，从"我的"页面进入）
- 退出/解散家庭（解散后 30 天可恢复，任意原成员均可操作）

**与其他模块的关系：**

- 日程管理：日程以家庭为边界，成员只能看到所属家庭的日程
- 打卡统计：统计以家庭 + 孩子为维度
- 孩子展示模式：影响孩子端整体 UI 渲染

## 2. 家庭创建流程

### 2.1 创建入口

| 场景 | 入口 | 行为 |
|------|------|------|
| 首次使用（无家庭） | 登录后显示引导页 | 引导用户创建或加入家庭 |
| 已有家庭，想再创建 | "我的"页面 → "创建家庭" | 创建后自动切换到新家庭 |
| 无家庭，想加入 | 引导页 → "加入家庭" | 输入邀请码加入 |

### 2.2 首次使用引导

```
登录成功 → 用户无家庭 → 显示统一引导页
  ┌──────────────────────────────────────┐
  │                                      │
  │   🏠                                 │
  │   欢迎使用家庭日程助手                 │
  │                                      │
  │   [创建家庭]      [加入家庭]          │
  │                                      │
  └──────────────────────────────────────┘
```

- **创建家庭**：输入家庭名称 + 自选角色 → 进入日历视图（空态）
- **加入家庭**：输入邀请码 → 以邀请码指定的角色加入 → 进入日历视图

### 2.3 创建流程

```
步骤 1：输入家庭名称
步骤 2：选择"我是谁"
  ┌──────────────────────────────────────┐
  │  创建家庭                            │
  │                                      │
  │  家庭名称  [________________]        │
  │                                      │
  │  我是                                │
  │  ● 家长  — 我可以管理日程和成员       │
  │  ○ 孩子  — 我只需要查看和执行日程     │
  │                                      │
  │              [创建]                  │
  └──────────────────────────────────────┘
```

**设计要点：**

| 要点 | 说明 |
|------|------|
| 家庭名称 | 必填，2-20 个字符，支持中英文和 emoji |
| 角色选择 | 创建者自选，默认"家长" |
| 同名家庭 | 允许同一用户创建多个同名家庭 |
| 创建后 | 创建者自动成为该家庭第一位成员，角色为所选角色 |
| 空态 | 创建后进入日历视图（空态），提示邀请成员 |

### 2.4 创建者选择"孩子"角色

创建者选择"孩子"角色时，家庭无家长。成员列表顶部提示"暂无家长，建议邀请家长来管理家庭"。其他功能与正常家庭一致，但孩子角色无管理权限（见第 4 节）。

### 2.5 设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 创建时自选角色 | 是 | 创建者不一定是家长，也可能是孩子帮家庭搭建 |
| 默认角色 | 家长 | 大多数场景是家长创建 |
| 用户无家庭时 | 无角色概念 | 角色存在于家庭中，不在家庭外 |

### 2.6 修改家庭名称

- 入口：成员列表页 → 点击家庭名称区域 → 进入编辑
- 权限：家庭中任一"家长"角色成员均可修改
- 规则：2-20 个字符，支持中英文和 emoji，与创建时一致
- 生效：保存后立即生效，所有成员看到新名称

## 3. 邀请机制

### 3.1 双轨邀请

| 方式 | 适用对象 | 载体 | 特点 |
|------|---------|------|------|
| 微信分享卡片 | 邀请其他家长 | 微信聊天/群聊分享 | 点击即加入，无需手动输入 |
| 邀请码 | 邀请孩子 / 无法使用微信分享时 | 6 位数字码 | 可口头告知，适合孩子场景 |

**谁可以邀请**：家庭中任一"家长"角色成员均可发起邀请。

### 3.2 邀请码设计

| 属性 | 规则 |
|------|------|
| 格式 | 6 位纯数字（如 382951） |
| 有效期 | 生成后 24 小时，过期自动失效 |
| 使用次数 | 一次性，使用后立即失效 |
| 角色预设 | 生成时由邀请人指定（家长 / 孩子），加入者无法更改 |
| 撤销 | 待使用的邀请码可由邀请人手动撤销 |

### 3.3 邀请家长流程

```
邀请人（家长）操作：
  成员列表页 → 点击"邀请成员" → 选择"邀请家长"
  → 微信分享面板弹出 → 选择聊天/群聊发送小程序卡片

被邀请人操作：
  微信聊天中点击小程序卡片 → 打开小程序
  → 显示确认页面：
  ┌──────────────────────────────────────┐
  │  加入"我们一家"                      │
  │                                      │
  │  邀请人：爸爸                        │
  │  你将作为 家长 加入此家庭             │
  │                                      │
  │       [取消]      [确认加入]          │
  └──────────────────────────────────────┘
  → 确认 → 加入成功 → 进入日历视图
```

**边界情况：**

| 场景 | 处理 |
|------|------|
| 被邀请人已在该家庭中 | 提示"你已是该家庭成员" |
| 家庭已满 10 人 | 提示"家庭已满，无法加入" |
| 分享卡片被转发给第三人 | 仍可加入（卡片不限转发对象） |

### 3.4 邀请孩子流程

```
邀请人（家长）操作：
  成员列表页 → 点击"邀请成员" → 选择"邀请孩子"
  → 输入孩子信息：
  ┌──────────────────────────────────────┐
  │  邀请孩子加入"我们一家"               │
  │                                      │
  │  孩子姓名  [________________]        │
  │                                      │
  │  展示模式  ● 学龄前  ○ 小学  ○ 高年级 │
  │                                      │
  │              [生成邀请码]             │
  └──────────────────────────────────────┘
  → 生成 6 位邀请码：
  ┌──────────────────────────────────────┐
  │  邀请码：382951                      │
  │                                      │
  │  有效期至：今晚 21:37                 │
  │                                      │
  │  将邀请码告诉孩子，或 [复制发送]      │
  └──────────────────────────────────────┘

被邀请人操作：
  "我的"页面 → "加入家庭" → 输入邀请码
  → 显示确认页面：
  ┌──────────────────────────────────────┐
  │  加入"我们一家"                      │
  │                                      │
  │  邀请人：爸爸                        │
  │  姓名：小明                          │
  │  你将作为 孩子 加入此家庭             │
  │                                      │
  │       [取消]      [确认加入]          │
  └──────────────────────────────────────┘
  → 确认 → 加入成功 → 进入日历视图（孩子端）
```

### 3.5 邀请码管理

家长可在成员列表页查看邀请记录：

| 邀请码 | 目标成员 | 角色 | 生成时间 | 状态 |
|--------|---------|------|---------|:--:|
| 382951 | 小明 | 孩子 | 今天 21:37 | 待使用 |
| 719402 | 妈妈 | 家长 | 昨天 10:00 | 已过期 |

- 待使用的邀请码可手动撤销
- 撤销后该邀请码立即失效，被邀请人输入时提示"邀请码已被撤销"

### 3.6 邀请码边界情况

| 场景 | 处理 |
|------|------|
| 邀请码过期（超过 24 小时） | 提示"邀请码已失效，请联系家长重新获取" |
| 邀请码已被使用 | 提示"邀请码已被使用" |
| 输入不存在的邀请码 | 提示"邀请码无效，请检查后重试" |
| 邀请码被撤销 | 提示"邀请码已被撤销" |
| 家庭已满 10 人 | 提示"家庭已满（10 人），无法加入" |
| 两人同时使用同一邀请码 | 第一个成功，第二个提示"邀请码已被使用" |

## 4. 成员列表与角色管理

### 4.1 成员列表页

```
┌──────────────────────────────────────┐
│  ← 家庭管理         我们一家          │
├──────────────────────────────────────┤
│                                      │
│  家长（2 人）                         │
│  ┌─────────────────────────────────┐ │
│  │ 👤 爸爸（我）          [家长]   │ │
│  │ 👤 妈妈                 [家长]   │ │
│  └─────────────────────────────────┘ │
│                                      │
│  孩子（2 人）                         │
│  ┌─────────────────────────────────┐ │
│  │ 👦 小明  学龄前模式        [>]  │ │
│  │ 👧 小红  小学模式          [>]  │ │
│  └─────────────────────────────────┘ │
│                                      │
│  ─────────────────────────────────── │
│  家庭人数：4/10                       │
│                                      │
│  [+ 邀请成员]                         │
│                                      │
│  ─────────────────────────────────── │
│  邀请记录                             │
│  ┌─────────────────────────────────┐ │
│  │ 382951  小明  孩子  待使用  [撤销]│ │
│  │ 719402  妈妈  家长  已过期       │ │
│  └─────────────────────────────────┘ │
│                                      │
│  ─────────────────────────────────── │
│  [退出家庭]                           │
│                                      │
└──────────────────────────────────────┘
```

### 4.2 成员操作

| 操作 | 对家长 | 对孩子 | 对自己 | 权限 |
|------|:--:|:--:|:--:|------|
| 查看详情 | ✓ | ✓ | ✓ | 所有人 |
| 设置展示模式 | — | ✓ | — | 仅家长 |
| 移除成员 | ✓ | ✓ | — | 仅家长 |
| 退出家庭 | — | — | ✓ | 所有人（创建者需先解散） |

### 4.3 移除成员

```
点击成员 → 弹出操作菜单
  ┌──────────────────────────────────────┐
  │  小明 · 孩子                         │
  │                                      │
  │  [设置展示模式]                       │
  │  [移除成员]                           │
  └──────────────────────────────────────┘

点击"移除成员" → 确认弹窗
  ┌──────────────────────────────────────┐
  │  移除"小明"？                        │
  │                                      │
  │  移除后，小明的日程数据将保留，       │
  │  但小明将无法再访问此家庭。           │
  │                                      │
  │       [取消]      [确认移除]          │
  └──────────────────────────────────────┘
```

**边界情况：**

- 移除后，被移除者进入"无家庭"状态（同首次登录引导页）
- 被移除者的历史打卡记录保留，但标记为"已离群"
- 无法移除自己（应走"退出家庭"流程）
- 家庭只剩最后一人时，不允许移除（应走"解散家庭"流程）
- 家长 A 移除成员 X，家长 B 同时也在操作该成员 → 后到达的操作失败，提示"该成员已不在家庭中"

### 4.5 孩子姓名显示规则

家长在邀请孩子时指定的"孩子姓名"（如"小明"）**仅在家庭内部使用**，覆盖孩子的微信昵称显示。

| 场景 | 显示 |
|------|------|
| 成员列表 | 孩子姓名 |
| 日程卡片孩子标签 | 孩子姓名 |
| 打卡记录中的孩子标识 | 孩子姓名 |
| 孩子端"我的"页面 | 孩子姓名 |
| 家长端数据看板 | 孩子姓名 |

孩子的微信昵称仅在其个人认证模块（"我的"页面编辑资料）中可见，家庭内所有场景统一使用孩子姓名。

### 4.6 角色管理

| 要点 | 说明 |
|------|------|
| 角色确定时机 | 加入家庭时确定（创建者自选 / 被邀请者由邀请码指定） |
| 角色变更 | 不支持。角色需要调整时：移除成员 → 重新邀请 → 以新角色加入 |
| 重新加入 | 历史数据保留（打卡记录等），同一用户身份未变 |

### 4.8 转让创建者

创建者可将创建者身份转让给家庭中的其他家长。

- 入口：成员列表 → 点击某家长 → "转让创建者"
- 确认弹窗：提示"转让后你将成为普通家长，对方将成为家庭创建者"，需二次确认
- 转让后：原创建者降为普通家长，接收者成为新创建者
- 限制：仅可转让给"家长"角色成员，孩子角色不可接收

**边界情况：**

| 场景 | 处理 |
|------|------|
| 家庭只有创建者一个家长 | 无可转让对象，隐藏转让入口 |
| 转让时网络异常 | 保持原状态，提示"操作失败，请重试" |
| 创建者被移除 | 不允许，创建者必须先转让或解散家庭 |

### 4.9 角色相关边界

| 场景 | 处理 |
|------|------|
| 创建者选"孩子"角色，家庭无家长 | 成员列表提示"暂无家长，建议邀请家长管理" |
| 所有家长退出，只剩孩子 | 最后一个家长退出时阻止，提示"请先将孩子移除或转让家庭" |
| 孩子试图进入管理页面 | 隐藏管理入口，URL 直接访问时重定向到首页 |

## 5. 孩子展示模式设置

### 5.1 设置入口

成员列表 → 点击孩子 → "设置展示模式"

### 5.2 设置界面

```
┌──────────────────────────────────────┐
│  ← 小明 · 展示模式                    │
├──────────────────────────────────────┤
│                                      │
│  选择适合小明的展示模式               │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │ 🧸  学龄前模式                   │ │
│  │     适合 3-6 岁                  │ │
│  │     大色块卡片、卡通图标、极少文字 │ │
│  │                         ● 已选   │ │
│  └─────────────────────────────────┘ │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │ 📋  小学模式                     │ │
│  │     适合 6-10 岁                 │ │
│  │     文字+图标列表、显示时间段     │ │
│  │                         ○       │ │
│  └─────────────────────────────────┘ │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │ 📱  高年级模式                   │ │
│  │     适合 10-14 岁                │ │
│  │     完整日程信息、可自主添加日程   │ │
│  │                         ○       │ │
│  └─────────────────────────────────┘ │
│                                      │
│  切换后立即生效，孩子端界面将更新。    │
│                                      │
│              [保存]                   │
│                                      │
└──────────────────────────────────────┘
```

### 5.3 设计要点

| 要点 | 说明 |
|------|------|
| 默认值 | 创建时由邀请人选择，无邀请人选择时默认"小学模式" |
| 生效时机 | 保存后立即生效，孩子端无需刷新 |
| 更改频率 | 无限制，家长可随时修改 |
| 孩子端感知 | 无通知，仅界面展示方式变化 |
| 预览 | 设置页面提供"预览孩子端"按钮，点击弹出半屏预览，模拟孩子端今日视图。仅视觉预览，不支持打卡等交互 |

### 5.4 三种模式对比

| 模式 | 目标年龄 | 视觉特征 | 交互能力 |
|------|---------|---------|---------|
| 学龄前 | 3-6 岁 | 大色块卡片、卡通图标、极少文字、颜色区分状态 | 点击大按钮完成打卡 |
| 小学 | 6-10 岁 | 文字+图标列表、显示时间段 | 打卡确认、查看完成进度 |
| 高年级 | 10-14 岁 | 接近成人视图、完整日程信息 | 打卡确认、可自主添加日程、查看统计 |

> 注：第一期不区分展示模式，统一使用小学模式。展示模式的差异化 UI 在第二期实现。

## 6. 多家庭切换

### 6.1 切换入口

"我的"页面中，"切换家庭"作为菜单项之一：

```
┌──────────────────────────────────────┐
│  我的                                │
├──────────────────────────────────────┤
│  👤 爸爸                             │
│                                      │
│  当前家庭：我们一家 · 家长             │
│                                      │
│  ─────────────────────────────────── │
│                                      │
│  > 切换家庭                           │
│  > 创建家庭                           │
│  > 加入家庭                           │
│  > 设置                              │
│                                      │
└──────────────────────────────────────┘
```

点击"切换家庭" → 进入切换面板。

### 6.2 切换面板

```
┌──────────────────────────────────────┐
│  切换家庭                            │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │ 🏠 我们一家                     │ │
│  │    家长 · 4 人           ● 当前 │ │
│  └─────────────────────────────────┘ │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │ 🏠 爷爷奶奶家                   │ │
│  │    家长 · 2 人                  │ │
│  └─────────────────────────────────┘ │
│                                      │
│  [创建新家庭]                         │
│                                      │
└──────────────────────────────────────┘
```

### 6.3 状态记忆

每个家庭独立记住：

| 状态项 | 说明 |
|--------|------|
| 上次视图 | 月/周/日，默认周视图 |
| 上次日期 | 上次查看的日期位置，默认"今天" |
| 筛选条件 | 按孩子/按类型筛选，默认"全部" |
| 上次活跃时间 | 用于排序切换列表（最近活跃的排前面） |

切换时立即恢复这些状态，用户看到的是上次离开时的样子。

### 6.4 切换行为

- 切换后立即跳转日历视图（首页），使用恢复的状态
- 切换不产生通知，不影响其他家庭成员
- 一个用户在多个家庭中可以有不同角色（如 A 家庭是家长，B 家庭是孩子）

### 6.5 边界情况

| 场景 | 处理 |
|------|------|
| 用户只有一个家庭 | "切换家庭"菜单隐藏或置灰 |
| 切换时网络异常 | 保持当前家庭，提示"切换失败，请重试" |
| 被移除的家庭在切换列表中 | 切换时提示"你已不在该家庭中"，自动从列表移除 |

## 7. 退出与解散家庭

### 7.1 退出家庭（非创建者）

入口：成员列表页底部 → "退出家庭"

```
┌──────────────────────────────────────┐
│  退出"我们一家"                      │
│                                      │
│  退出后：                            │
│  · 你将无法查看此家庭的任何日程       │
│  · 你的打卡记录将被保留               │
│  · 你可以通过重新邀请加入此家庭       │
│                                      │
│       [取消]      [确认退出]          │
└──────────────────────────────────────┘
```

**边界情况：**

- 退出后，用户进入"无家庭"状态（首次登录引导页）
- 退出不影响其他成员，日程数据保留
- 如果该用户关联的日程仍在进行中，日程保留但不再显示该成员
- 创建者不允许退出，提示"创建者无法退出，请先解散家庭"
- 最后一个家长不允许退出（如果家庭中还有孩子），提示"请先将孩子移除或转让家庭"

### 7.2 解散家庭（创建者）

入口：成员列表页底部 → "解散家庭"

```
┌──────────────────────────────────────┐
│  解散"我们一家"                      │
│                                      │
│  ⚠ 此操作将解散整个家庭，所有成员     │
│    将无法访问此家庭。                 │
│                                      │
│  数据保留 30 天，期间任何成员可恢复。  │
│  30 天后数据永久删除。                │
│                                      │
│  输入家庭名称确认：                   │
│  [________________]                  │
│                                      │
│       [取消]      [确认解散]          │
└──────────────────────────────────────┘
```

**设计要点：**

| 要点 | 说明 |
|------|------|
| 确认方式 | 输入家庭名称（防止误操作） |
| 解散后状态 | 所有成员进入"无家庭"状态 |
| 数据保留 | 30 天，从解散时刻起算 |
| 恢复权限 | 任意原家庭成员均可恢复 |
| 到期处理 | 第 31 天自动物理删除，不可恢复 |

### 7.3 恢复家庭

解散后，原家庭成员登录时看到提示：

```
┌──────────────────────────────────────┐
│  家庭"我们一家"已解散                 │
│                                      │
│  数据保留至 2026 年 11 月 22 日       │
│  （剩余 23 天）                       │
│                                      │
│  [恢复家庭]      [知道了]             │
└──────────────────────────────────────┘
```

**设计要点：**

| 要点 | 说明 |
|------|------|
| 恢复后状态 | 所有数据、成员关系完整恢复 |
| 创建者身份 | 不变，仍是原创建者 |
| 反复操作 | 30 天内可反复解散/恢复 |
| 多人恢复 | 以第一个恢复的为准，后续恢复者直接加入 |
| 到期后恢复 | 提示"数据已过期删除，无法恢复" |

### 7.4 退出 vs 解散

| 维度 | 退出家庭 | 解散家庭 |
|------|---------|---------|
| 操作者 | 任何非创建者成员 | 仅创建者 |
| 影响范围 | 仅自己 | 所有成员 |
| 数据保留 | 保留，退出者可重新加入 | 保留 30 天，可恢复 |
| 确认方式 | 二次确认 | 输入家庭名称 |
