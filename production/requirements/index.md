## 1. 产品概述

### 1.1 产品定位

**"家庭日程协作工具"** -- 一款微信小程序，帮助家长规划和安排孩子的日程，孩子查看并执行。覆盖课后活动、日常作息、作业任务三种场景，适配 3-14 岁不同年龄段孩子的使用习惯。

### 1.2 核心价值

- **家长端**：统一规划孩子的课后活动、日常作息、作业任务，一个工具管理所有安排
- **孩子端**：清晰看到"今天要做什么"，按适合自己的方式查看和完成日程
- **家庭协作**：多家长共享管理，数据云端同步

### 1.3 平台策略

- **首期**：微信小程序（家长端 + 孩子端在同一小程序内通过角色区分）
- **后续**：根据产品使用情况评估是否需要 Web 端

## 2. 用户角色

### 2.1 角色定义

| 角色 | 说明 |
|------|------|
| **家长** | 家庭创建者或受邀管理员，负责创建和管理日程 |
| **孩子** | 家庭中的孩子成员，查看和执行分配给自己的日程 |

### 2.2 账户模型

**个人账户 + 家庭绑定模式**：

- 每个用户通过微信登录，拥有独立的个人账户
- 一个用户可以属于多个家庭（如爸爸同时属于"自己家"和"爷爷奶奶家"）
- 家长可以创建/加入多个家庭
- 孩子只属于一个家庭
- 家长在多个家庭之间切换

### 2.3 权限矩阵

| 能力 | 家长 | 孩子 |
|------|:--:|:--:|
| 创建/管理家庭 | ✓ | ✗ |
| 邀请成员加入家庭 | ✓ | ✗ |
| 设置孩子展示模式 | ✓ | ✗ |
| 创建/编辑/删除日程 | ✓ | ✗（高年级模式可自主添加） |
| 配置日常作息时间槽 | ✓ | ✗ |
| 创建/管理模板 | ✓ | ✗ |
| 分配日程给孩子 | ✓ | ✗ |
| 查看日程（月/周/日视图） | ✓ | ✓ |
| 打卡确认（完成/未完成） | ✓ | ✓ |
| 查看完成统计 | ✓ | ✓（仅自己） |
| 切换家庭（多家庭场景） | ✓ | ✗ |

### 3.2 模块一：认证与账户

**功能描述**：用户通过微信授权登录小程序，创建个人账户。

**功能点**：

- 微信一键登录（获取微信 openid 和用户基本信息）
- 首次登录自动创建账户
- 查看/编辑个人资料（头像、昵称）
- 账户与微信绑定

> 详细设计见认证与账户模块文档（待创建）。

### 3.3 模块二：家庭管理

**功能描述**：家长创建家庭、邀请成员、管理家庭成员和孩子的展示模式。

**功能点**：

- **创建家庭**：家长创建家庭，输入家庭名称
- **邀请成员**：通过微信分享卡片/小程序码邀请其他家长加入；通过邀请码添加孩子
- **成员列表**：查看家庭成员列表，区分家长和孩子
- **角色管理**：设置成员为家长或孩子
- **切换家庭**：家长在多个家庭之间切换（如"自己家""爷爷奶奶家"）
- **孩子设置**：为每个孩子配置展示模式（学龄前 / 小学 / 高年级）
- **退出/解散家庭**：成员可退出家庭；创建者可解散家庭

> 详细设计见家庭管理模块文档（待创建）。

### 3.4 模块三：日程管理

**功能描述**：家长创建、编辑、删除日程，支持三种日程类型，将日程分配给指定孩子。孩子查看并打卡执行。

**核心能力**：创建/编辑/删除/查看日程、三种日程类型、时间槽模型、重复日程管理、临时取消、打卡确认。

> **详细设计见 [日程管理模块文档](module-event.md)**，涵盖：日程类型设计、时间槽模型、CRUD 流程、编辑/删除/取消交互、日程详情页、日历视图关系、打卡与状态。

### 3.5 模块四：模板系统

**功能描述**：提供预设模板和自定义模板，帮助家长快速创建日程。

**功能点**：

- **预设模板**：系统内置常用模板，如"每日作息套餐""课后班模板""作业模板"
- **自定义模板**：家长可将已有日程保存为模板，或从零创建新模板
- **模板参数**：模板可包含时间、类型、重复规则、备注等，使用时只需填入具体日期和关联孩子
- **一键创建**：选择模板 → 填入参数 → 一键生成日程
- **模板管理**：查看、编辑、删除自定义模板

> 详细设计见模板系统模块文档（待创建）。

### 3.6 模块五：日历视图

**功能描述**：以日历形式展示日程，支持月视图、周视图、日视图三种视图，按孩子和日程类型筛选，颜色区分类型。

> **详细设计见 [日程管理模块文档 - 第 9 节](module-event.md#9-与日历视图的关系)**，涵盖：三视图展示形式、信息密度、颜色区分策略、筛选逻辑、状态视觉呈现、默认视图、日期跳转。

### 3.7 模块六：打卡与统计

**功能描述**：孩子和家长对日程进行打卡确认，系统记录完成情况并生成统计。

**功能点**：

- **打卡确认**：对日程项进行"完成"确认操作
- **打卡时间记录**：记录实际打卡时间
- **完成状态**：已完成 / 未完成 / 逾期未完成 / 已取消
- **连续完成统计**：日常作息类日程的连续完成天数
- **完成率统计**：按日/周/月统计完成率
- **数据看板**（家长端）：查看每个孩子的完成情况概览
- **我的统计**（孩子端）：查看自己的完成统计
- **订阅消息提醒**：通过微信小程序订阅消息推送日程提醒

> 打卡交互细节见 [日程管理模块文档 - 第 10 节](module-event.md#10-打卡与状态)。详细设计见打卡与统计模块文档（待创建）。

## 4. 日程类型

三种日程类型（课后活动 / 日常作息 / 作业任务）的详细设计、字段定义、行为差异、时间槽模型，已移至 [日程管理模块文档 - 第 2 节](module-event.md#2-日程类型设计)。

| 类型 | 典型场景 | 时间模型 | 打卡语义 |
|------|---------|---------|---------|
| 课后活动 | 钢琴课、游泳课、补习班 | 时间槽，周重复 | 确认到场 |
| 日常作息 | 起床、练琴、阅读、睡觉 | 时间槽，周重复 | 完成打卡 |
| 作业任务 | 学校作业、学习任务 | 截止日期，不重复 | 完成即归档 |

## 5. 孩子展示模式

孩子端界面根据家长为孩子设置的展示模式，呈现不同的视觉和交互体验。系统根据孩子年龄自动推荐默认模式。

| 模式 | 目标年龄 | 视觉特征 | 交互能力 |
|------|---------|---------|---------|
| **学龄前模式** | 3-6 岁 | 大色块卡片、卡通图标、极少文字、颜色区分状态 | 点击大按钮完成打卡 |
| **小学模式** | 6-10 岁 | 文字+图标列表、显示时间段 | 打卡确认、查看完成进度 |
| **高年级模式** | 10-14 岁 | 接近成人视图、完整日程信息 | 打卡确认、可自主添加日程、查看统计 |

**配置方式**：家长在"家庭管理 → 孩子设置"中为每个孩子选择展示模式，可随时更改。

> 详细设计见孩子展示模式模块文档（待创建）。

## 7. 数据模型概要

> 注：此节为概念模型，非数据库设计。具体表结构在技术设计阶段确定。

### 核心实体

- **用户（User）**：微信 openid、昵称、头像、角色（家长/孩子）
- **家庭（Family）**：家庭名称、创建者、创建时间
- **家庭成员（FamilyMember）**：用户-家庭关联、角色、展示模式（孩子）
- **日程（Event）**：名称、类型、重复规则、创建者、关联孩子
- **时间槽（TimeSlot）**：日程的时间配置（7 天独立配置，存储星期几 + 开始/结束时间）
- **模板（Template）**：模板名称、类型、预设内容（含时间槽）、创建者
- **打卡记录（Checkin）**：日程关联、打卡时间、状态、打卡人 ID
- **取消记录（Cancellation）**：日程实例关联、取消日期、操作人

### 关系概要

```
User ──┬── FamilyMember ──┬── Family
       │                  │
       │                  ├── ChildSetting（展示模式等）
       │                  │
       │                  ├── Event ── TimeSlot
       │                  │     │
       │                  │     ├── Checkin
       │                  │     └── Cancellation
       │                  │
       │                  └── Template
       │
       └──（个人账户独立）
```

## 8. 非功能需求

### 8.1 性能

- 页面首屏加载时间 ≤ 2 秒
- 日历视图切换（月/周/日）响应时间 ≤ 500ms
- 打卡操作响应时间 ≤ 1 秒

### 8.2 兼容性

- 支持微信小程序基础库版本 ≥ 2.10.0
- 支持 iOS 12+ 和 Android 8.0+ 系统

### 8.3 安全性

- 微信登录认证，所有 API 需携带登录态
- 日程数据按家庭隔离，非家庭成员不可访问
- 敏感操作（删除日程、移除成员等）需二次确认

### 8.4 可用性

- 学龄前模式界面需符合幼儿认知水平（大按钮、少文字、颜色区分）
- 关键操作（创建日程）流程不超过 3 步
- 网络异常、数据为空等边界状态有友好提示

## 9. 分期规划

### 第一期：核心日程框架

- 微信登录与账户体系
- 家庭创建与成员管理
- 日程 CRUD（三种类型 + 时间槽）
- 月视图 + 周视图 + 日视图
- 模板系统（预设 + 自定义）
- 打卡确认
- 孩子端今日视图 + 周视图 + 月视图（统一视图，暂不区分展示模式）

### 第二期：体验增强

- 孩子展示模式（学龄前/小学/高年级）
- 打卡统计与数据看板
- 微信订阅消息提醒
- 多家庭切换与数据隔离

### 第三期：智能与扩展

- 高年级孩子自主添加日程
- 成就/奖励系统
- Web 端评估与开发
- 更多模板与智能推荐
