> 版本：v1.0 | 日期：2026-08-05 | 状态：草案
>
> 所属产品：[家庭日程协作工具](index.md)
>
> 本文档为 `index.md` 的模块化拆分，聚焦模板系统模块的详细设计。其他模块设计见对应模块文档。

---

## 1. 模块概述

模板系统帮助家长快速创建日程，减少重复录入。模板保存日程的"内容骨架"（名称、类型、时间槽、重复规则、备注），使用时只需指定关联孩子和生效起始日期，一键生成日程。

**核心能力：**

- 系统预设模板（3 个，覆盖三种日程类型）
- 从日程保存为模板（复用已有日程的配置）
- 从零创建自定义模板
- 选模板 → 指定孩子 + 起始日期 → 一键生成日程
- 模板编辑/删除（不影响已生成的日程）
- 家庭内共享（自定义模板同家庭家长可见）

**与其他模块的关系：**

- 日程管理：模板用于快速创建日程，生成后与普通日程无异
- 家庭管理：模板在家庭范围内共享，非家庭成员不可见

## 2. 模板结构设计

### 2.1 核心原则：模板 = 预填好的日程草稿

模板不搞独立的字段体系，直接复用日程的字段结构。创建模板时先选日程类型，模板的字段自然由该类型决定。

### 2.2 字段划分：模板保存 vs 使用时填写

| 字段 | 模板中 | 使用时 | 说明 |
|------|:---:|:---:|------|
| 日程名称 | ✓ 保存 | 可覆盖 | 模板提供默认名称，使用时可修改（如"钢琴课"改为"小提琴课"） |
| 日程类型 | ✓ 固定 | 不可改 | 课后活动的模板不会用来生成作业任务 |
| 时间槽 | ✓ 保存 | 可覆盖 | 模板提供默认时间，使用时可微调 |
| 重复规则 | ✓ 保存 | 可覆盖 | 同上 |
| 备注 | ✓ 保存 | 可覆盖 | 模板备注作为提示，使用时补充具体信息 |
| 关联孩子 | ✗ | ✓ 必填 | 模板不知道要给谁用 |
| 生效起始日期 | ✗ | ✓ 必填 | 模板不知道从哪天开始 |

### 2.3 模板与日程类型的关系

模板继承日程的三种类型，创建模板时先选类型，字段结构遵循该类型的规则：

| 模板类型 | 对应日程类型 | 时间模型 | 重复规则 |
|------|------|------|------|
| 课后活动模板 | 课后活动 | 时间槽（7 天独立配置） | 周重复 |
| 日常作息模板 | 日常作息 | 时间槽（7 天独立配置） | 周重复 |
| 作业任务模板 | 作业任务 | 截止日期（不设时间槽） | 不重复 |

> 日程类型的详细字段定义见 [日程管理模块文档 - 第 2 节](module-event.md#2-日程类型设计)。

## 3. 预设模板

### 3.1 概述

系统内置 3 个预设模板，覆盖三种日程类型，所有用户可见。

### 3.2 预设模板清单

| 预设模板 | 类型 | 预填内容 |
|------|------|------|
| 课后班模板 | 课后活动 | 名称：课后班，时间槽：周三 16:00-17:00，重复：每周 |
| 日常作息模板 | 日常作息 | 名称：练琴，时间槽：每天 18:00-18:30，重复：每周 |
| 作业模板 | 作业任务 | 名称：作业，备注：完成课本习题，重复：不重复 |

### 3.3 预设模板的特性

- **不可编辑、不可删除**：预设模板由系统维护，用户不可修改
- **所有用户可见**：不限制家庭范围，全员可用
- **可作为创建自定义模板的起点**：用户选择预设模板 → 修改字段 → 另存为自己的模板

## 4. 模板创建

### 4.1 两种创建入口

| 入口 | 场景 | 流程 |
|------|------|------|
| **从日程保存** | 已经创建了一个日程，想复用 | 日程详情页 → "保存为模板" → 确认 |
| **从零创建** | 还没有日程，想先建模板 | 模板管理页 → "新建模板" → 填写字段 |

### 4.2 从日程保存为模板

```
日程详情页 → 点击"保存为模板"
  ↓
确认保存
  ↓
模板创建成功，提示"已保存为模板，可在模板管理中查看"
```

**要点：**

- 日程的所有字段（名称、类型、时间槽、重复规则、备注）自动带入模板
- 关联孩子和生效日期不保存到模板中
- 保存后模板与日程独立，后续修改日程不影响模板，反之亦然

### 4.3 从零创建模板

```
模板管理页 → 点击"新建模板"
  ↓
步骤 1：选择日程类型
  ┌──────────────────────────────────────┐
  │  新建模板                            │
  │                                      │
  │  选择模板类型                        │
  │  ● 课后活动  — 有固定时间段的课外活动 │
  │  ○ 日常作息  — 每日例行事项          │
  │  ○ 作业任务  — 一次性学习任务        │
  │                                      │
  │              [下一步]                │
  └──────────────────────────────────────┘
  ↓
步骤 2：填写模板内容（表单字段根据所选类型动态展示）
  ┌──────────────────────────────────────┐
  │  新建课后活动模板                     │
  │                                      │
  │  模板名称  [____钢琴课_____________]  │
  │                                      │
  │  时间设置                            │
  │  周一 [--:--] ~ [--:--]              │
  │  周二 [--:--] ~ [--:--]              │
  │  周三 [16:00] ~ [17:00]              │
  │  ...                                 │
  │                                      │
  │  重复规则  每周重复                   │
  │                                      │
  │  备注      [____带上琴谱___________]  │
  │                                      │
  │              [保存模板]              │
  └──────────────────────────────────────┘
```

**要点：**

- 与创建日程共用同一套表单逻辑，区别是不填写"关联孩子"和"生效日期"
- 模板名称必填，不能为空

## 5. 一键创建日程

### 5.1 使用流程

```
模板管理页 → 点击模板卡片
  ↓
弹出"使用模板"面板
  ┌──────────────────────────────────────┐
  │  使用模板：钢琴课                      │
  │                                      │
  │  模板预览（可修改）                    │
  │  名称       [钢琴课_______________]   │
  │  类型       课后活动                  │
  │  时间槽     周三 16:00-17:00          │
  │  重复       每周                      │
  │  备注       [带上琴谱______________]  │
  │                                      │
  │  ── 以下为必填 ──                     │
  │  关联孩子   [▼ 小明]                  │
  │  起始日期   [2026-08-10]              │
  │                                      │
  │              [创建日程]              │
  └──────────────────────────────────────┘
  ↓
日程创建成功，跳转到日程详情页
```

### 5.2 交互要点

| 要点 | 说明 |
|------|------|
| 模板字段可覆盖 | 除"日程类型"外，所有模板字段使用时可修改，不影响原模板 |
| 关联孩子必填 | 单选，从家庭成员中的孩子列表选择 |
| 起始日期必填 | 默认为当天，可修改 |
| 创建成功后 | 跳转到新创建的日程详情页，底部 toast 提示"创建成功" |
| 取消 | 关闭面板，不保存任何修改 |

## 6. 模板管理

### 6.1 模板列表

```
模板管理页
┌──────────────────────────────────────────┐
│  ← 模板管理                              │
│                                          │
│  [搜索模板...]              [新建模板]    │
│                                          │
│  ┌─ 预设模板 ──────────────────────────┐ │
│  │  📋 课后班模板   课后活动            │ │
│  │  📋 日常作息模板   日常作息          │ │
│  │  📋 作业模板     作业任务            │ │
│  └────────────────────────────────────┘ │
│                                          │
│  ┌─ 我的模板 ──────────────────────────┐ │
│  │  📋 钢琴课       课后活动  周三 16:00│ │
│  │  📋 游泳课       课后活动  周六 09:00│ │
│  │  📋 数学作业     作业任务            │ │
│  └────────────────────────────────────┘ │
│                                          │
│  空态：                                  │
│  ┌────────────────────────────────────┐ │
│  │  📋                                │ │
│  │  还没有自定义模板                    │ │
│  │  从日程保存或新建模板开始            │ │
│  │            [新建模板]              │ │
│  └────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

### 6.2 模板编辑

```
模板管理页 → 点击模板 → 进入模板详情页 → 点击"编辑"
```

- 编辑模板等同于修改模板的预填字段（名称、时间槽、重复规则、备注）
- 编辑后**不影响**之前用该模板已生成的日程
- 模板与日程是"生成时复制"关系，非"引用"关系

### 6.3 模板删除

```
模板详情页 → 点击"删除" → 确认弹窗
  ┌──────────────────────────────────────┐
  │  删除模板                            │
  │                                      │
  │  确定删除模板"钢琴课"吗？             │
  │                                      │
  │  已有 3 个日程使用过此模板，           │
  │  删除模板不会影响这些日程。            │
  │                                      │
  │         [取消]    [确认删除]          │
  └──────────────────────────────────────┘
```

**要点：**

- 预设模板不可删除
- 删除模板不影响已生成的日程
- 确认弹窗中提示使用次数，消除用户顾虑
- 删除后不可恢复

### 6.4 查找模板

- 模板列表顶部提供搜索框，按模板名称模糊搜索
- 首期不做分类/标签，模板的日程类型本身即为分类
- 预设模板和自定义模板分区展示

## 7. 共享范围

### 7.1 共享规则

| 模板类型 | 可见范围 | 谁可以使用 |
|------|------|------|
| 预设模板 | 全局 | 所有用户 |
| 自定义模板 | 家庭内 | 同家庭的所有家长 |

### 7.2 设计要点

- 家庭是协作单位，一个家长创建的模板，同家庭其他家长也能看到和使用
- 孩子角色不可见模板管理页（孩子无创建日程权限）
- 家长切换到不同家庭时，看到的自定义模板是当前家庭的模板

| 能力 | 首期 | 二期 |

| 系统预设模板（3 个） | ✓ | — |

| 从零创建自定义模板 | ✓ | — |
| 选模板 + 指定孩子 + 起始日期 → 一键生成日程 | ✓ | — |

| 模板删除 | ✓ | — |
| 家庭内共享 | ✓ | — |
| 组合模板（每日作息套餐等） | ✗ | ✓ |
| 模板分类/标签 | ✗ | ✓ |

## 9. 边界与异常

| 场景 | 处理 |
|------|------|
| 模板名称为空 | 阻止保存，提示"请输入模板名称" |
| 使用模板时未选择孩子 | 阻止创建，提示"请选择孩子" |
| 使用模板时未选择起始日期 | 阻止创建，提示"请选择起始日期" |
| 模板列表为空（自定义模板） | 显示空态引导："还没有自定义模板，从日程保存或新建模板开始" |
| 删除模板时模板已被使用 | 正常删除，提示"已有 N 个日程使用过此模板，删除模板不会影响这些日程" |
| 家庭无孩子成员 | 使用模板时孩子选择器为空，提示"请先在家庭中添加孩子" |
| 切换家庭 | 模板列表刷新为当前家庭的模板 |
