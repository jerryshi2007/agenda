# 家庭日程协作工具 · UI 设计总览

## 设计交付物

| 文件 | 说明 |
|------|------|
| `prototype/common.css` | 完整设计系统（令牌、组件库、布局） |
| `prototype/index.html` | 18 个屏幕的高保真 UI 设计展示 |

## 设计系统要点

- **品牌色**: Indigo Violet `#6366F1`，温暖优雅，家庭友好
- **日程类型色**: 课后活动 蓝 `#3B82F6` / 日常作息 绿 `#22C55E` / 作业任务 橙 `#F59E0B`
- **字体**: PingFang SC（小程序默认），4px 基础间距
- **组件**: 按钮、标签、头像、进度环、分段控件、底部操作表等完整组件库

## 涵盖的 18 个屏幕

### 家长端 · 日历视图（3屏）
1. 周视图（默认首页）— 7列网格 + 彩色日程卡片 + 筛选栏
2. 日视图 — 时间线布局，完整信息 + 状态标签
3. 月视图 — 传统日历网格 + 色点标识

### 家长端 · 日程详情与创建（5屏）
4. 日程详情页 — 状态区 + 基本信息 + 打卡记录 + 操作按钮
5. 创建步骤1 — 选孩子（多选卡片）
6. 创建步骤2 — 选类型（三类型卡片 + 模��入口）
7. 创建步骤3 — 填写字段（时间槽快速填充 + 微调）
8. 创建步骤4 — 预览确认

### 家长端 · 家庭管理（3屏）
9. 家庭成员列表 — 按角色分组 + 邀请记录
10. 孩子展示模式设置 — 三模式卡片选择
11. 多家庭切换 — 卡片列表 + 状态记忆

### 家长端 · 我的与数据（2屏）
12. 我的页面 — 个人中心 + 数据概览 + 快捷入口
13. 数据看板 — 完成率统计、按孩子/类型查看

### 孩子端（2屏）
14. 今日视图 — 时间线 + 大打卡按钮 + 进度环
15. 我的页面 — 连续打卡 + 完成率 + 最近完成

### 引导页（3屏）
16. 首次使用引导 — 品牌展示
17. 创建家庭 — 输入名称 + 自选角色
18. 加入家庭 — 6位邀请码输入 + 角色确认

## 设计特色

- 温暖的 Indigo 品牌色，区别于冷峻的蓝色 AI 风
- 清晰的视觉层次，家长端数据丰富、孩子端简洁友好
- 统一的圆角系统（10-20px），柔和不失专业
- 完整的组件库和设计令牌系统，可扩展
