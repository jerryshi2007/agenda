## 1. 产品概述

模板系统帮助家长快速创建日程，减少重复录入。模板保存日程的"内容骨架"（名称、类型、时间槽、重复规则、备注），使用时只需指定关联孩子和生效起始日期，一键生成日程。

**核心价值**：减少重复录入，提升创建日程效率。

## 2. 用户角色

| 角色 | 权限 |
|------|------|
| 家长 | 可查看/使用所有模板（预设 + 家庭自定义）、创建自定义模板、编辑/删除自己创建的模板 |
| 孩子 | 不可访问模板管理页面，无创建/编辑权限 |

权限矩阵：
- 预设模板：所有用户可见可用，不可编辑删除
- 自定义模板：同家庭家长可见可用，创建者可编辑删除
- 数据隔离：不同家庭之间模板不可见

## 4. 模板类型详细设计

模板继承日程的三种类型：

| 模板类型 | 对应日程类型 | 时间模型 | 重复规则 |
|------|------|------|------|
| 课后活动模板 | 课后活动 | 时间槽（7 天独立配置） | 周重复 |
| 日常作息模板 | 日常作息 | 时间槽（7 天独立配置） | 周重复 |
| 作业任务模板 | 作业任务 | 截止日期（不设时间槽） | 不重复 |

### 字段保存规则

| 字段 | 模板中保存 | 使用时填写 | 说明 |
|------|:---:|:---:|------|
| 日程名称 | ✓ | 可覆盖 | 提供默认值，使用时可修改 |
| 日程类型 | ✓ 固定 | ✗ 不可改 | 类型不可变 |
| 时间槽 | ✓ | 可覆盖 |  |
| 重复规则 | ✓ | 可覆盖 |  |
| 备注 | ✓ | 可覆盖 |  |
| 关联孩子 | ✗ | ✓ 必填 | 模板不知道给谁用 |
| 生效起始日期 | ✗ | ✓ 必填 | 模板不知道从哪天开始 |

详见 [module-template.md#2-模板结构设计](../../requirements/module-template.md#2-模板结构设计)。

## 6. 页面结构

| 页面 | 位置 | 功能说明 |
|------|------|------|
| 模板管理列表页 | 一级页面（通过"我的"或日程创建页入口） | 展示预设模板 + 自定义模板分区、搜索、新建入口 |
| 模板详情/编辑页 | 二级页面 | 查看模板详情、编辑模板字段 |
| 使用模板弹窗 | 模板列表页唤起 | 预览模板、填写必填项（孩子/起始日期）、创建日程 |

## 7. 业务概念模型

- **模板** = 日程草稿骨架，包含可复用的字段配置
- **生成关系**：使用模板时复制字段生成新日程，模板与生成的日程独立
- **模板 ≠ 日程**：模板本身不产生实例，仅作为创建日程的模板
- **共享范围**：预设模板全局共享，自定义模板家庭内共享

---

## 8. 非功能需求

- **性能**：模板列表加载 ≤ 500ms，创建日程响应 ≤ 1s
- **兼容性**：微信基础库 ≥ 2.10.0，iOS 12+ / Android 8.0+
- **安全性**：数据按家庭隔离，跨家庭不可访问；孩子角色无编辑权限
- **可用性**：所有操作支持取消，删除前二次确认，提示明确

### 边界与异常处理

完整边界异常处理参见 [module-template.md#9-边界与异常](../../requirements/module-template.md#9-边界与异常)：

| 场景 | 处理方式 |
|------|------|
| 模板名称为空 | 阻止保存，提示"请输入模板名称" |
| 使用模板时未选择孩子 | 阻止创建，提示"请选择孩子" |

| 家庭无孩子成员 | 提示"请先在家庭中添加孩子" |
| 切换家庭 | 模板列表刷新为当前家庭 |
