核心价值

三个角色视角，一个协作工具

长

家长端 · 统一规划

课后活动、日常作息、作业任务，一个工具管理孩子所有安排；模板一键生成重复日程，月/周/日三视图随时掌握全貌。

孩

孩子端 · 清晰执行

打开就是「今天要做什么」，时间线一目了然；做完打卡，完成进度可视化，按年龄段适配最易理解的方式。

协

家庭协作 · 云端同步

多家长共享管理，谁有空谁排；数据云端同步，换手机不丢，多家庭（爷爷奶奶家）轻松切换。

功能模块

六项能力覆盖家庭日程全流程

证

认证与账户

微信一键登录，个人账户 + 家庭绑定，数据按家庭隔离。

  • 微信原生授权登录
  • 隐私政策可控
家

家庭管理

创建/加入家庭，邀请成员，多家庭切换。

  • 微信分享 + 邀请码双轨邀请
  • 家长 / 孩子角色划分
历

日程管理

三种日程类型 + 时间槽模型，月/周/日三视图。

  • 按孩子 / 类型筛选
  • 颜色区分日程类型
板

模板系统

预设模板 + 自定义模板，一键生成重复日程。

  • 3 个系统预设模板
  • 从日程保存为模板
卡

打卡统计

孩子打卡执行，家长看完成率数据看板。

  • 日 / 周 / 月完成率
  • 连续完成天数
适

孩子展示模式

按孩子年龄适配展示形态，自动推荐。

  • 学龄前大色块卡片
  • 小学图标列表 / 高年级完整视图

使用场景

家长与孩子视角的日常

家长视角

安排一目了然

  • 孩子放学后：钢琴、游泳、作业怎么排，日历一眼看全
  • 多孩子家庭：按孩子筛选，各自安排互不干扰
  • 固定作息：模板一键生成每日重复日程
  • 完成情况：看板查看每个孩子的完成率
孩子视角

今天要做什么

  • 打开小程序就是今日任务时间线
  • 做完一项打一次卡，进度看得见
  • 成就与连续打卡激励，养成好习惯
