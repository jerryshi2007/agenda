# ADDED Requirements: family-lifecycle

家庭生命周期管理：创建/修改名称/多家庭切换/退出/解散/恢复。

---

## Requirement 1: 家庭创建

**描述**：用户无家庭时可创建新家庭，创建者自选角色（家长/孩子，默认家长）。

**Scenarios**

```gherkin
Scenario: 首次登录无家庭，创建家庭成功
  Given 用户已登录且无任何家庭
  When 用户在引导页点击"创建家庭"，输入家庭名称"我们家"，选择角色"家长"，点击创建
  Then 家庭创建成功
  And 用户成为该家庭第一个成员，角色为家长
  And 跳转到日历视图（空态），提示"快去邀请成员吧"

Scenario: 创建者选择孩子角色
  Given 用户已登录且无任何家庭
  When 用户创建家庭，输入名称"我们家"，选择角色"孩子"，点击创建
  Then 家庭创建成功
  And 用户成为该家庭第一个成员，角色为孩子
  And 成员列表顶部提示"暂无家长，建议邀请家长管理"
  And 展示模式默认为小学模式
  And 用户可在成员列表点击自己，将角色修改为家长

Scenario: 创建家庭名称长度不足 2 字符
  Given 用户已登录且无任何家庭
  When 用户输入名称"我"，点击创建
  Then 创建失败
  And 提示"家庭名称需要 2-20 个字符"
```

## Requirement 2: 修改家庭名称

**描述**：家长可修改家庭名称，修改后全家庭成员立即可见。

**Scenarios**

```gherkin
Scenario: 已有家庭，家长修改名称
  Given 用户是某家庭家长，家庭名称为"旧名称"
  When 用户在成员列表点击家庭名称区域，进入编辑，输入"新名称"保存
  Then 家庭名称立即更新为"新名称"
  And 所有家庭成员看到新名称

Scenario: 孩子尝试修改名称
  Given 用户是某家庭孩子成员
  When 用户尝试访问修改名称接口
  Then 修改被拒绝
  And 提示"孩子角色无权执行此操作"
```

## Requirement 3: 多家庭切换

**描述**：用户属于多个家庭时可在"切换家庭"页面切换，每个家庭独立记忆上次视图/日期/筛选状态。

**Scenarios**

```gherkin
Scenario: 用户属于两个家庭，切换家庭
  Given 用户属于家庭 A 和家庭 B，当前在家庭 A，上次查看是周视图，日期周一
  When 用户在"我的"页面点击"切换家庭"，选择家庭 B
  Then 切换到家庭 B
  And 恢复家庭 B 上次记忆的视图和日期
  And 跳转到日历视图

Scenario: 用户被移除出家庭，切换列表仍显示该家庭
  Given 用户被移除出家庭 A，用户仍有家庭 B
  When 用户在切换列表点击家庭 A
  Then 提示"你已不在该家庭中"
  And 家庭 A 从切换列表中移除

Scenario: 用户只有一个家庭
  Given 用户只加入了一个家庭
  Then "我的"页面中"切换家庭"菜单项隐藏
```

## Requirement 4: 退出家庭

**描述**：非创建者成员可退出家庭，创建者不能退出（必须先解散）。

**Scenarios**

```gherkin
Scenario: 非创建者成员退出
  Given 用户 A 是家庭非创建者成员
  When 用户 A 在成员列表底部点击"退出家庭"，二次确认
  Then 用户 A 被移除出家庭
  And 用户 A 进入无家庭状态，回到引导页

Scenario: 创建者尝试直接退出
  Given A 是家庭创建者，家庭还有其他成员
  When A 尝试执行退出家庭操作
  Then 提示"创建者无法退出，请先解散家庭"
  And 退出操作被阻止

Scenario: 最后一个家长尝试退出，家庭仍有孩子
  Given 家庭只有一个家长 A，还有 2 个孩子
  When A 尝试执行退出家庭操作
  Then 提示"请先将孩子移除或转让家庭给其他家长，才能退出"
  And 退出操作被阻止
```

## Requirement 5: 解散家庭

**描述**：创建者可解散家庭，解散需输入家庭名称确认，解散后数据保留 30 天可恢复。

**Scenarios**

```gherkin
Scenario: 创建者解散家庭，输入名称正确确认
  Given A 是家庭创建者
  When A 在成员列表底部点击"解散家庭"，输入正确家庭名称确认
  Then 家庭状态变为"已解散"
  And 所有成员进入无家庭状态
  And 数据标记为待删除，保留 30 天

Scenario: 创建者解散家庭，输入名称错误
  Given A 是家庭创建者
  When A 输入错误的家庭名称
  Then 解散失败
  And 提示"家庭名称不匹配，请重新输入"

Scenario: 家庭只剩最后一人，任何角色均可解散
  Given 家庭只剩用户一人，角色是孩子
  When 用户点击解散家庭，输入名称确认
  Then 家庭解散成功
```

---

## Requirement 6: 恢复解散家庭

**描述**：解散后 30 天内，任意原成员可恢复家庭。

**Scenarios**

```gherkin
Scenario: 解散后 30 天内恢复
  Given 家庭"我们家"已解散，还在 30 天保留期内
  When 任意原成员登录，看到恢复提示，点击"恢复家庭"
  Then 家庭恢复正常状态
  And 所有成员关系和数据完整恢复
  And 创建者身份不变

Scenario: 超过 30 天试图恢复
  Given 家庭已解散超过 30 天，数据已永久删除
  When 用户试图恢复
  Then 提示"数据已过期删除，无法恢复"
  And 恢复失败
```
