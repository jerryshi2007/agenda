## Why

用户进入系统的第一道门槛。作为所有后续模块（家庭、日程、打卡）的前置依赖，认证与账户模块必须在首期完成。当前无任何认证基础设施，用户无法登录、无法管理个人资料、无法注销账户。

## What Changes

- **新增**：隐私政策弹窗与同意机制（含版本管理）
- **新增**：微信静默登录链路（wx.login → code 换 openid → JWT 签发）
- **新增**：JWT 登录态管理（签发、存储、请求携带、静默续期、并发锁）
- **新增**：昵称头像收集页（微信原生控件，可跳过）与用户资料编辑
- **新增**："我的"页面（头像昵称区 + 家庭操作入口 + 设置入口）
- **新增**：账户注销与 30 天缓冲恢复机制
- **新增**：后端 API：登录、续期、资料读写、注销、恢复

## Capabilities

### New Capabilities

- `auth-login`: 隐私政策同意（含版本号管理）与微信静默登录（wx.login → openid → JWT），覆盖首次登录、新用户自动创建、Token 存储清除后重新登录、微信账号切换
- `auth-token`: JWT 签发/验签、请求自动携带、401 静默续期（含并发锁）、续期失败降级、频率限制、密钥管理
- `auth-profile`: 首次昵称头像收集（微信原生控件、可跳过、默认值兜底）、编辑资料页（头像更换、昵称修改、校验与事务一致性）
- `auth-my-page`: "我的"页面（头像昵称区、当前家庭信息、创建/加入/切换家庭入口、设置入口），按有无家庭展示不同布局；TabBar 结构（日历 + 我的）
- `auth-deletion`: 账户注销（含条件检查、二次确认）、30 天缓冲恢复、到期永久删除、打卡记录匿名化、接口幂等性

### Modified Capabilities

（无。认证模块为全新模块，不修改现有 spec。）

## Impact

- **后端**：新增 `api/` 目录下的 Auth 云函数/Controller，含登录/续期/资料/注销/恢复 API
- **前端**：新增 `app/` 目录下的隐私政策弹窗组件、昵称头像收集页、"我的"页面、编辑资料页、设置/注销页
- **数据库**：新增 User 表、隐私同意记录表、注销记录表
- **跨模块**：认证完成后交接给家庭模块（输出 userId + JWT）；"我的"页面提供家庭操作入口（跳转家庭模块页面）
- **依赖**：无上游模块依赖，本模块是其他所有模块的前置条件
